## 1. 目的

2026-10-30 の通しテストで、管理者 → SES → EG の登録の流れが NG になった（どんなメールが届くかわからない、仮登録 → 本登録が抜けている、本登録の項目がそろっていない）。ここを要件どおりに作り直す。ゴールは [v0.2.0-01-ゴール.md](v0.2.0-01-ゴール.md)。

## 3. スコープ

### 3-1. やること

- 画面：上位が下位を登録する画面（管理者 → 管理者・SES、SES → 担当者・EG）、仮登録メールから入る本登録の画面
- メール：仮登録メール（件名・本文・リンク・期限）、本登録が済んだ知らせ
- 状態：仮登録・本登録・参加中を足し、一覧・詳細に出す
- データ：SES の本登録の必須項目（企業正式名称・代表者姓名・住所・電話番号）。担当者の姓名は担当者本人の本登録で取る（K14）

### 3-2. やらないこと

- 案件から先（R07〜R12）
- 公開の申し込み（SES が自分から申し込む入口）の作り直し（K09 で確認）

## 5. 前提・制約

- 手元（GENESIS／FOCUS）で作り、公開版に反映して TEZZO が確かめる（反映は常時了承）。
- 公開版には管理者 TEZZO のほか、テスト用の SES 1社・エンジニア 1人がいる（TEZZO が残すと決めた。2026-10-31）。本物の利用者はいないので、移し替えは要らない。
- 個人情報は公開リポジトリに書かない。テストのメールアドレスはテスト用のものを使う。

## 6. 完了の条件

- 管理者 → 管理者、管理者 → SES、SES → 担当者、SES → EG のそれぞれで、次が通る。
  1. 上位が仮登録すると、K01 の仮登録メールが届く。
  2. メールから本登録の画面に入り、必須項目（K03・K04・K05・K14）がそろわないと進めない。
  3. 本登録が済むと、K11 のとおり参加中になり、K10 のとおり上位に知らされる。
  4. 一覧・詳細に、状態が正しく出る（K08）。
  5. 期限切れ・送り直し（K07）が決めたとおりに動く。
- 上の全部が、テスト設計書の項目になり、エビデンス（画面・届いたメール）が残っている。
