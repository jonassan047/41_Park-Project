## 共通：どの流れでも確かめる形（F）

段階の表の「F 一式」は、その流れ（上位 → 下位）について次のすべてを行う。

| 番号 | 手順 | 期待 | 元 |
|---|---|---|---|
| F1 | 上位が必須項目を入れて仮登録 | 下位の行が「仮登録」で作られ、参加中ではない。パスワードなし、期限7日 | K01・K17 |
| F2 | 上位が必須項目を1つ抜く（項目ごと） | 断られ、行もメールもできない | 8章 |
| F3 | 仮登録メール | 件名・宛名（企業名・姓・名）・登録した人・立場・リンク・期限・その立場の必須項目・心当たりがない案内が入る。文は要件定義書の付録のとおり | K01・付録 |
| F4 | リンクを開く | 本登録の画面に上位が入れた内容が入って出る。「見」の項目は直せない | K16・8章 |
| F5 | 必須項目を1つずつ抜いて保存 | 進めない。行は変わらない | 8章 |
| F6 | 保存したが確認コードを入れない | 仮登録のまま、ほかの画面を開けず、上位に知らせが行かない。リンクは期限まで使える | K18・K27 |
| F7 | 途中でやめて、同じリンクから入り直す | 前に入れた値は DB に残っていない | K18 |
| F8 | 間違った確認コード／正しいコード | 間違いは進めない。正しければ参加中になり、本登録の日時が入り、ホームへ。リンクは使えなくなる | K11・K17・K27 |
| F9 | 完了のあと | K25 の相手に K10 のとおりメールと通知。同じ人に重ねて送らない | K10・K25 |
| F10 | 一覧・詳細 | 仮登録／仮登録（期限切れ）／参加中 が正しく出る。送り直しボタンは仮登録の間だけ | K08・K17 |
| F11 | 期限切れ（8日目）のリンク | 使えない。上位に頼む案内が出る | K07 |
| F12 | 上位が送り直す | 新しいリンクが届き、前のリンクは無効。権限のない人は押せない | K07・K29 |
| F13 | 「心当たりがない」 | リンクが無効になり、上位に知らせが届く。本人の情報は確定しない | K27 |
| F14 | 仮登録中に上位がメール・企業名・姓・名を直す | 同じ行のまま変わる（2行にならない）。メールを直すと新しいアドレスへ送り直し、古いリンクは無効 | K29・B5 |
| F15 | 仮登録の人のログイン・`/account`・`/welcome`・他の画面 | どこにも入れない | K06・B6・K33 |

## テストでは確かめられないもの（人が見るもの）

自動テストの外に置き、エビデンスに「未実施」と書く。

- 本物のメールが届くこと（今回は送らない）。
- 本登録の画面と一覧の見た目（TEZZO さんのレビューで見る。手元で開けたら画面を撮る）。
- 公開版での動き（段階の区切りごとに `park-deploy.sh` で反映する。画面の確認は TEZZO さん）。
