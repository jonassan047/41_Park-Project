# PARK v0.2.0 テスト実施結果エビデンス

実施日: 2026-11-01（作成：Leo）。対応表は [テスト設計書](v0.2.0-03-テスト設計書.md) の末尾。

## 1. 自動テスト（`tests/Feature`、メモリ上の SQLite）

| 段階 | commit（park） | Feature の件数 | 失敗 |
|---|---|---|---|
| 段階1 | `3f227ea` | 505 | 1（既知） |
| 段階2 | `691b234` | 540 | 1（既知） |
| 段階3＋レビュー修正 | `4a51619` | 578 | 1（既知） |

- 失敗の1件は `EngineerDetailTest`（profile histories and documents）。手元の CLI の PHP に zip 拡張（`ZipArchive`）が無いことによるもので、v0.2.0 の前からある。アプリの不具合ではない。
- 実行：`.env` を作らず `APP_KEY` を渡して `php artisan test --testsuite=Feature`（`jonassan_park` の DB には触れていない。メールは送らず `mail_outbox` で確かめた）。アドレスは `@example.com` と見本の `@park.example` だけ。
- 段階2の途中で出た失敗3件の原因：テストの戻り値の型（`?object`）、管理者の交代で整数の `user_id` を弾いていたこと（`AdminController::changeRep` を直した）。
- 各 AC のテスト名は計画の番号（`test_s2_07_…`、`test_s3_10_registration_flow` など）。S3-10 は7本（管理者→管理者・SES・担当者・EG、代表者→担当者・EG、担当者→EG）で、仮登録メール → 本登録 → 確認コード → 参加中 → 知らせ → 一覧の状態をたどる。

## 2. レビュー（park-reviewer、読む専用）

- high 2件を直した：取り消しで、前からいる人の技術データまで消える（技術データがあれば `engineers` を残し、アカウントだけ消す）／仮登録の直し（`POST /people/{id}`）に回数制限が無い（`throttle:30,1`）。
- low 12件（L1〜L12）は**未対応**。内容：会社が停止中でも送り直しでアカウントができる／仮登録の直しで停止中の人にもメールが出る／所属を移すと応募・契約の会社がずれる／AI の下書きから仮登録中の EG に経験票を足せる／次の代表者を直せない・交代で宙に浮く／次の代表者の本登録で前の代表者に知らせが無い／代表者に知らせるときに使える人か見ていない／記録に氏名・前後のアドレスが残る（`engineer-create`・`admin-edit`）／仮登録の会社の代表者だけ取り消すと代表者のいない会社が残る／`park:invite-admin` に記録が無い／`/setup` のアドレス重複で 500。次のサイクルで扱う。
