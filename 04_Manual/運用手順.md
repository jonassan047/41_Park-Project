# PARK の運用手順（tezzo 向け）

PARK を動かし続けるために、tezzo がすることと、ジョー（とエージェント）に頼むことの手順。CLI（黒い画面）は使わず、WIZ の入力欄でジョーに頼めば足りるように書いた（2026-10-17）。
アプリの画面の使い方は、[運営向け](運営向け.md)・[SES向け](SES向け.md)・[エンジニア向け](エンジニア向け.md) のマニュアルを見る。

## 1. 毎朝（自動）

FOCUS を起動すると、その日の最初の1回だけ、ジョーのエージェント（park-manager）が PARK を点検する。tezzo がすることはない。

- 点検の結果は [40_動作確認](../40_動作確認) に `その日の日付-NN-点検.md` で残る（WIZ の 41_Park-Project の画面から読める）。
- 問題があれば、[92_FromJoe](../92_FromJoe/CURRENT.md) の「次にやること」に1行出る。
- 気になったら、ジョーにこう頼む：

```
今朝の PARK の点検の結果を見て、直すところがあれば直して
```

## 2. 公開版にログインする

1. https://www.jona.jp/park/login を開く。
2. メールアドレスとパスワードを入れる。
3. メールで届いた6桁の確認コードを入れる（10分間有効。届かなければ迷惑メールを見るか「コードを送り直す」）。
4. ホームのいちばん上の「今やること」から片付ける。

## 3. 人を増やす

| こんなとき | すること |
|---|---|
| SES が参加を申し込んだ | 運営のホームの「今やること」に出る。内容を確かめて「承認」。担当者に招待メールが届く |
| SES を運営から登録したい | 運営の「SES」→「SES を登録」→ 承認。担当者に招待メールが届く |
| エンジニアを登録したい | SES（または運営）が「エンジニアを登録」。メールアドレスを入れると本人に招待メールが届く |
| 運営を増やしたい（阿部さんなど） | ジョーに頼む（下の囲み）。招待のリンクを作る |
| 招待のリンクの期限（7日）が切れた | エンジニアの詳細の「招待を送る」、または SES の詳細で送り直す |

```
PARK の運営に（名前）さんを追加したい。招待のリンクを作って
```

## 4. 直してほしいとき・足してほしいとき

ジョーに、何をどうしたいかを頼む。ジョーが開発チーム（計画 → 実装 → レビュー → テスト）で直し、テストが通ったら、公開版にも反映する（反映は tezzo の常時了承あり。2026-10-17）。

```
PARK のここを直して：（どの画面で、何が困っているか）
```

## 5. 手元の AI

面談スクリプトの言い回し・経歴書からの下書きは、FOCUS の中の AI が作る。

- FOCUS がついている間だけ動く。FOCUS が止まっていると、「AI に頼む」を押しても順番待ちのままになる（FOCUS を起動すれば、続きから進む）。
- 動いているかは、運営の「AI」の画面の「AI が最後に取りに来た」で見る。
- 1件に数十秒〜数分かかる。できたら知らせが届くので、中身を確かめて「採用する」（または「経験票に足す」）を押す。

## 6. 困ったとき

| こんなとき | すること |
|---|---|
| 確認コードのメールが届かない | 迷惑メールのフォルダを見る。それでもなければ「コードを送り直す」。続くなら、ジョーに「PARK のメールが届かない」と伝える |
| 公開版が開かない | ジョーに「PARK の点検をして」と頼む |
| AI の下書きが返ってこない | FOCUS がついているか確かめる。続くなら、ジョーに「PARK の AI が動かない」と伝える |
| 朝の点検を止めたい・AI を止めたい | ジョーに頼む（スタートアップの「PARK 朝の点検」「PARK AI つなぎ役」を外す） |

## 7. 必ず tezzo の了承が要ること

ジョーは、次のことを勝手にしない。頼むときは、はっきり「やって」と伝える。

- 公開版の設定（`.env`：メールの送り元・合言葉など）を変える
- データを消す（本番で使い始める前の、見本データの削除など）
- メールを一斉に送る

```
公開版の見本データを消して（了承します）
```
