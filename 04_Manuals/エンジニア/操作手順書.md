# PARK 操作手順書（エンジニアのみなさま向け）

はじめて PARK を使うエンジニアのみなさまが、**ログイン → 設定 → 届くメールの処理**を、この順に進めるための手順書です。画面ごとの細かい説明は「エンジニア向けマニュアル」にあります。

## 1. 初めてのログイン

所属の SES（または管理者）があなたを登録すると、PARK から**招待メール**（件名：ご招待：パスワードを設定してください）が届きます。

1. 招待メールのリンクを開きます（期限は7日。切れていたら、所属の SES（直属の人は管理者）に送り直してもらいます）。
2. 「パスワードの設定」の画面で、パスワード（8文字以上）を2回入れます。
3. 「個人情報の取り扱い」を読み、「上の取り扱いに同意します」にチェックを入れて「**設定して始める**」を押します。
4. 登録のメールアドレスに、**確認コード**のメール（件名：確認コード 123456）が届きます。6桁のコードを「確認コード」の画面に入れて「ログイン」を押します（10分間有効）。
5. 「**あなたの情報**」の画面が出ます。氏名（姓・名。どちらも必須）・ふりがな（姓・名）・電話を入れて「**登録する**」を押します（最初の1回だけ。あとから「アカウント」で直せます）。
6. ホームの画面が開けば、ログインは完了です。画面の上に、「エンジニアとしてログインしています」と出ます。

## 2. 2回目からのログイン

1. PARK のトップの右上の「ログイン」を押します。
2. メールアドレスとパスワードを入れて「ログイン」。前にログインしたことがあれば、メールアドレスは最初から入っています。
3. 届いた確認コードのメールの6桁を入れて「ログイン」。

| こんなとき | すること |
|---|---|
| 確認コードが届かない | 迷惑メールのフォルダを見ます。無ければ画面の「コードを送り直す」 |
| 10分すぎてしまった・まちがえすぎた | 確認コードの画面を開き直すと、新しいコードが自動で届きます（まちがえすぎたときは、1分ほどたってから開き直します）。新しいメールの6桁を入れます |
| パスワードを忘れた | ログインの画面の「パスワードを忘れたとき」から、再設定のメールを受け取ります |
| 別の人のアカウントで入ってしまった | 確認コードの画面の「別のアカウントでログインする」 |

## 3. 最初の設定

ログインしたら、上から順に済ませます。ホームのいちばん上の「**今やること**」にも、やることが順に出ます。

### 3-1. 登録の内容の確認（必須）

1. ホームの「**登録の内容の確認**」を開きます。
2. 所属の SES や管理者が入れた内容（名前・連絡先・経歴など）を確かめ、違うところは直します。
3. 「**確認しました**」を押します。

確認が済むまで、案件に応募できません。登録の内容は、あなたご自身が責任を持つものです。SES や管理者が書き換えたときは、もう一度確認します。

### 3-2. アカウントの設定

1. 右上のお名前 →「**アカウント**」を開きます。
2. 「基本」の上の「**登録情報を見る**」を押すと、今の登録内容を見るだけの画面が開きます（「編集する」でアカウントに戻れます）。「基本」では、氏名（姓・名）・ふりがな（姓・名）・電話を確かめます。「**メールでも通知を受け取る**」には、チェックを入れたままにしてください（外すと、案件のご案内や面談の知らせがメールで届かず、画面のベルだけになります）。「保存」を押します。
3. パスワードを変えるときは、「パスワードの変更」に今のパスワードと新しいパスワード（2回）を入れて「変更」。
4. メールアドレスはここでは変えられません。変えるときは、所属の SES か管理者に連絡します。

### 3-3. プロフィール・スキル・経験票

合う案件が届くようにするための設定です。上のメニューの「プロフィール」から入れます。

1. 「基本情報」の「編集」：強み（ひとこと）・自己PR・希望単価・下限の単価・稼働できる日・希望の働き方・今の状態。案件を探していないときは、今の状態を「今は休止」にします。
2. 「スキルを編集」：スキル名・年数・レベル（5つ以上がおすすめ）。
3. 「案件を追加」：これまでの案件を、直近から2件以上。**事実だけ**を書きます。
4. 手持ちの経歴書があれば、「データ領域」に上げて「AI で経験票の下書き」を押すと、下書きが作れます（中身は必ず確かめます）。

## 4. 届くメールの処理

PARK からのメールは、どれも最後に「▼詳しくはこちら」のリンクが付いています。押すと、PARK の該当の画面が開きます（ログインしていなければ、ログインのあとに開きます）。

| 届くメール（件名） | すること |
|---|---|
| ご招待：パスワードを設定してください | 上の「1. 初めてのログイン」 |
| 確認コード 123456 | ログインの画面に6桁を入れる。心当たりがないときは無視して、パスワードを変える |
| **案件のご案内**（所属の SES、またはグループの担当者から） | 下の「4-1」 |
| あなたに合う案件が届きました | PARK の「届いた案件」で案件票を見て、応募するか見送るかを決める |
| 案件に応募しました | 控えです。することはありません |
| 面談が決まりました（◯回目） | 下の「4-2」 |
| 面談を通過しました／見送り | 「応募・面談」で次の段階を確かめる |
| 成約おめでとうございます | ホームの「経歴の更新」から、経験票に案件を追加する |
| 経歴を更新してください | 案件が終わったお知らせ。「終わった案件を書く」から、終わった月と成果を書き足す |
| 契約が延長されました | 確かめるだけ |
| 管理者からメッセージが届きました | 「やり取り」で読んで、返事をする |

### 4-1. 案件のご案内メールに返事をする

1. メールの案件の内容（金額・必須スキル・場所・開始・期間・働き方）と、あなたとの相性を読みます。
2. メールの最後のリンクから、1つを押します。
   - **応募したい**：条件が合い、出てみたいとき。
   - **質問がある**：条件で確かめたいことがあるとき。
   - **見送る**：出ないとき。
3. 開いた画面で、ひとこと（気になる条件・質問・見送りの理由）を書き、「**この内容で返事をする**」を押します。ログインは要りません。
4. 所属の SES から直接届いたメールには、そのまま返信してもかまいません（担当者に届きます）。グループの案件（PARK から届いたもの）は、返信しても担当者に届かないので、必ずリンクから返事をします。
5. 「応募したい」と返事をすると、担当者があなたの書類を添えて応募します。面談の依頼が来たら、またメールでお知らせします。

### 4-2. 面談が決まったら

1. 「面談が決まりました」のメールのリンク、またはホームの「面談の予定」から、**面談スクリプト**を開きます。
2. 合う点・足りない点、先方が確かめたいこと、想定質問と答え方のヒントを読みます。
3. 右側の「自分用のメモ」に、答えの練習を書いておきます。
4. 面談のあと、結果はメールでお知らせします。
