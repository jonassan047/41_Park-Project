# PARK 操作手順書（SES 企業さま向け）

PARK にご参加の SES 企業のご担当者さまが、**ログイン → 設定 → メールの処理**を、この順に進めるための手順書です。画面ごとの細かい説明は「SES 企業さま向けマニュアル」にあります。

## 1. 初めてのログイン

参加のお申し込みを管理者が承認すると（または管理者が貴社を仮登録すると）、SES さまに PARK から**仮登録のご案内メール**（件名：仮登録のご案内：本登録をお願いします）が届きます。本登録が済むまで、PARK のほかの画面は使えません。

1. メールのリンクを開きます（期限は7日。切れていたら、管理者に送り直しをご依頼ください。お心当たりがない場合は、画面の「心当たりがない」を押します）。
2. 「本登録」の画面に、企業正式名称と SES のお名前が入っています。お確かめのうえ、違っていれば直します。
3. 会社の**電話番号・郵便番号・住所**とパスワード（8文字以上、2回）を入れ、守秘義務への同意にチェックを入れて「**本登録する**」を押します。
4. 登録のメールアドレスに、**確認コード**のメール（件名：確認コード 123456）が届きます。6桁のコードを入れて「ログイン」を押します（10分間有効）。入れるまでは何も保存されません。
5. ダッシュボードが開けば、本登録は完了です（参加中になります）。画面の上に、「SES（貴社名）のご担当者としてログインしています」と出ます。会社の情報の編集は、SES だけができます。
6. 必須の項目や同意が足りないと言われたときは、「足りない項目の画面」が開きます。足りない項目を入れると、いつもの画面に進めます。

## 2. 2回目からのログイン

1. PARK のトップの右上の「ログイン」を押します。
2. メールアドレスとパスワードを入れて「ログイン」。前にログインしたことがあれば、メールアドレスは最初から入っています。
3. 届いた確認コードの6桁を入れて「ログイン」。

| こんなとき | すること |
|---|---|
| 確認コードが届かない | 迷惑メールのフォルダを見ます。無ければ画面の「コードを送り直す」 |
| 10分すぎてしまった・まちがえすぎた | 確認コードの画面を開き直すと、新しいコードが自動で届きます（まちがえすぎたときは、1分ほどたってから開き直します）。新しいメールの6桁を入れます |
| パスワードを忘れた | ログインの画面の「パスワードを忘れたとき」から、再設定のメールを受け取ります |

## 3. 最初の設定

ログインしたら、上から順に済ませます。ダッシュボードのいちばん上の「**今やること**」にも、やることが順に出ます。

### 3-1. 会社情報の確認（任意）

1. 上のメニューの「**SES**」を開きます。
2. 企業正式名称・SES・電話番号・郵便番号・所在地などを確かめ、違うところは直して保存します（編集できるのは SES だけです。ご担当者は見るだけです）。
3. 会社の情報は、貴社が責任を持つものです。変わったら、いつでもここから直せます。

### 3-2. アカウントの設定

1. 右上のお名前 →「**アカウント**」を開きます。
2. 「基本」の上の「**登録情報を見る**」を押すと、今の登録内容を見るだけの画面が開きます（「編集する」でアカウントに戻れます）。「基本」では、氏名（姓・名）・ふりがな（姓・名）・所属・役職・電話を確かめます（企業名は、「SES」の画面の「会社情報」から、SES が直します）。「**メールでも通知を受け取る**」には、チェックを入れたままにしてください（外すと、エンジニアの返事・面談・成約・請求の知らせがメールで届かず、画面のベルだけになります）。「保存」を押します。
3. パスワードを変えるときは、「パスワードの変更」で変えます。
4. メールアドレスの変更は、管理者にご連絡ください。SES の交代も管理者にご依頼ください（SES は、交代のあとでなければ停止・退会にできません）。

### 3-3. 担当者の登録（SES だけ）

1. 上のメニューの「**SES**」を開き、「担当者」の欄の「**担当者を登録**」を押します（SES の画面にだけ出ます。担当者の画面には出ません）。
2. **姓・名・メールアドレス**の3つを入れて「仮登録してメールを送る」を押します。担当の方に、仮登録のご案内（件名：仮登録のご案内：本登録をお願いします）が届きます。電話番号と守秘義務への同意は、担当の方が本登録で入れます。
3. 担当の方が確認コードまで進むと、「担当者」の欄が「参加中」になり、あなたに本登録のお知らせが届きます。
4. 本登録が済む前の方の行には、「**送り直し**」「**仮登録の内容を直す**」「**取り消し**」が出ます。メールが届かないと言われたら「送り直し」を押します。間違えて登録したときは「取り消し」で消せます。
5. 本登録が済んだ担当者の「停止」「再開」「退会」も、この表の行のボタンで行えます（ご自身の行と、SES の行には出ません。使える担当者が1人だけのときは、その人は止められません）。

### 3-4. エンジニアの登録（SES・担当者）

1. 「エンジニア」→「**エンジニアを登録**」。
2. **姓・名・メールアドレス**の3つを入れて「仮登録してメールを送る」。メールアドレスは必須です。ふりがな・電話・郵便番号・住所・個人情報の取り扱いへの同意は、ご本人が本登録で入れます。
3. 登録すると、ご本人に仮登録のご案内が届きます。本登録が済むまでは「仮登録」と出て、案件の配信の候補にも出ません（技術・経歴・住所などは、貴社は入れられません）。
4. メールが届かないと言われたら、エンジニアの一覧か詳細の「**送り直し**」で送り直します。間違えて登録したときは「取り消し」で消せます。
5. 本登録のあと、貴社のエンジニアのスキル表・経験票は、SES・担当者のどちらも、詳細の「スキルを登録・編集」「案件を追加」から直せます。直すと、ご本人の「確認しました」がやり直しになります。仮登録中は直せません。スキルはチェック式で、年数は4段階（1年未満・1年以上・3年以上・5年以上）です。画面には、業務経験・業界・業務領域（それぞれ当てはまるものすべて。業務経験と業務領域は案件の点数に使われます）と、役割で PM・PL を選んだときだけ出る3問（それぞれ1つ）があります。PM・PL を外して保存すると、3問の回答は消えます。

### 3-5. ご自身もエンジニアとして登録する（兼任）

1. 「エンジニア」→「エンジニアを登録」で、姓・名と、メールアドレスに**ご自分のログイン用のメールアドレス**を入れて登録します（仮登録のご案内は出ません）。
2. 「ログアウト」して入り直します。確認コードのあと、「どの立場で入りますか」の画面で「**エンジニア**」を選びます。
3. 初めてのときは、足りない項目の画面が出ます。ふりがな・電話・郵便番号・住所と、個人情報の取り扱いへの同意を入れて進みます（同意が、登録の内容の確認を兼ねます）。

立場を変えるときは、ログアウトして入り直します（入ったあとの切り替えボタンはありません）。兼ねられるのは貴社のエンジニアだけです。

## 4. メールの処理

貴社が扱うメールは、**元請けとのメール**（PARK の外）と、**PARK から届くメール**の2つです。

### 4-1. 元請けから案件メールが届いたら

1. 「案件」→「**案件を登録**」。
2. 届いた案件メールの本文をコピーし、「**案件メールから取り込む**」に貼り付けて「取り込む」。案件名・金額・必須スキル・場所・開始などが自動で入ります（外部のサービスには送りません）。
3. 抜けているところ・違うところを直します。元請けの名前は伏せ字でかまいません。必須・尚可の文から拾った**業務経験・業務領域**は、「業務経験・業務領域（必須・尚可）」に「必須」「尚可」で選んであります（項目ごとに「—／必須／尚可」を選び直せます）。エンジニアの点数と足りない点に使われます。
4. 「登録する」。管理者にも知らせが届きます。登録すると、手元の AI が必須・尚可を読み直します（1件 1分ほど）。
   - 規則と同じ数で、人が直しておらず、案内もまだなら、AI の結果が自動で入ります。
   - そうでないときは、登録した人に知らせが届きます。案件の画面の「**AI の読み直し**」で、違いの表を見て「AI の結果を使う」か「今のままにする」を選びます（貴社の案件だけ）。
   - 案内したあとは、AI の結果は自動では入りません。

### 4-2. エンジニアに案件を案内する

1. 登録した案件の画面で「**エンジニアに案内する**」。
2. **送る相手を絞る**：合う順に候補が出ます。チェックで足したり外したりします。
3. **メールを作る**：「すべて同じ内容」か「一人ずつ変える」を選び、件名と本文を書きます（{呼び名}・{案件名}・{単価} などの差し込みが使えます）。
4. **送る前に確かめる**：一人ずつの本文と「提案」（点数が低い、足りないスキルなど）を見て、送らない人はチェックを外します。
5. **送る**。メールの最後に「応募したい／質問がある／見送る」のリンクが付きます。

### 4-3. エンジニアから返事が来たら

| 返事の来方 | すること |
|---|---|
| ご本人がメールのリンクを押した | 自動で記録され、「◯◯ さん 応募したい：案件名」などのメールが貴社に届きます。することは下の「4-4」へ |
| 貴社のメールに直接返信が来た | 案件の画面の「案内メール」で、その人の返事（応募したい／質問あり／見送り）を選び、要点を書いて「**記録**」 |
| 質問が来た | 貴社から答え、答えたあとの返事を記録します |

### 4-4. 元請けへ書類を返す

1. 案件の画面の「案内メール」の欄で、「応募したい」の人の**履歴書**・**業務経歴書**（名前を伏せた版も）を Excel でダウンロードします。
2. 元請けへの返信メールに添付して送ります（PARK の外）。
3. 送ったら、PARK で「**書類を返した（応募した）**」を押します。応募の画面ができます。

### 4-5. 元請けから面談依頼・結果のメールが来たら

1. **面談依頼**：応募の画面の「**面談依頼が来た**」に、日時・場所（URL）・先方が確かめたいこと（1行に1つ）を入れて記録します。面談スクリプトができ、ご本人と管理者に知らせが届きます。
2. **面談の結果**：面談の画面の「結果を記録」で、通過／見送りと先方の印象を残します。
3. **成約**：応募の画面の「成約を記録」で、金額・開始日・契約の終わりを入れます。
4. **見送り**：応募の画面の下で、理由を選んで「見送りにする」。

### 4-6. PARK から届くメール

どのメールにも「▼詳しくはこちら」のリンクがあり、押すと PARK の該当の画面が開きます。

| 届くメール（件名） | すること |
|---|---|
| 確認コード 123456 | ログインの画面に6桁を入れる |
| ◯◯ さん 応募したい（質問あり・見送り）：案件名 | 上の「4-3」「4-4」 |
| 貴社のエンジニアが応募しました | 「応募・選考」で中身を確かめる |
| グループの案件が、貴社のエンジニアに届きました | 確かめるだけ（ほかの SES・管理者が貴社のエンジニアに案内した知らせ） |
| エンジニアの推薦がありました | 貴社の案件に、ほかの SES から推薦が来た知らせ。案件の画面の「エンジニアに案内する」の「グループのほかの人」から案内する |
| 面談が決まりました／面談通過 | 「応募・選考」で日程と次の段階を確かめる |
| 成約しました | 確かめるだけ。成功報酬の請求に入ります |
| 契約が延長されました | 確かめるだけ |
| ◯◯ 分のご請求書 | 「請求」で請求書を開き、「印刷・PDF に保存」で保存して、お支払いの手続きをする |
