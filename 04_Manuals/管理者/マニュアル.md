# PARK 管理者マニュアル

PARK を管理する人（管理者）向けの手順書です。SES 企業さま向け・エンジニア向けのマニュアルは、それぞれ別にあります。

## 1. PARK の流れ（全体）

1. **SES の参加**：SES 企業が参加を申し込み、管理者が承認します（または管理者が仮登録します）。SES に**仮登録のご案内**が届き、SES が**本登録**（確認コードまで）を済ませると、参加中になります。
2. **担当者・エンジニアの登録**：SES・担当者や管理者が、担当者・エンジニアの**姓・名・メールアドレス**を入れて仮登録します。本人に仮登録のご案内が届き、本人が**本登録**（確認コードまで）を済ませると、参加中になります。エンジニアは、本登録のあとに本人が経歴（経験票）を入れます。本登録が済むまで、エンジニアは配信の候補に出ません。
3. **スキルシートを整える**：管理者は、本人とやり取りしながら、事実にもとづいたスキルシートに仕上げます。
4. **案件の登録**：元請けから届いた案件を、管理者か SES が登録します。
5. **マッチングと配信**：条件に合うエンジニアを選んで、案件を配信します（本人と所属 SES にメール）。
6. **応募**：エンジニアが条件を確かめて応募します（SES が代わりに出すこともできます）。
7. **選考**：スキルシート提出 → 書類通過 → 面談（面談対策の Q&A を自動で作成）→ 結果。
8. **成約**：契約を記録します。成功報酬（初期費用・月額費用）は請求書に入ります。
9. **成約後**：配属後のフォロー、契約の延長・終了を記録します。

いちばん大事にするのは、**エンジニアの成約率を上げること**です。合わない人に送らない、条件を応募の前に確かめる、面談の準備をする、落ちた理由を記録して次に活かす、の4つを続けます。

## 2. はじめに

### ログイン（2要素認証）

- ログインは、パスワードと、メールで届く6桁の**確認コード**の2つで行います。認証アプリなどの設定はいりません。
- メールアドレスとパスワードを入れると、そのメールアドレスに確認コードが届きます（10分間有効）。届かないときは、画面の「コードを送り直す」を押します。10分すぎてから画面を開くと、新しいコードが自動で届きます。
- 初めてのログイン（仮登録のご案内のリンクで本登録をしたあと）も、確認コードを入れます。確認コードを入れると、本登録が完了します。

### 本登録（最初の情報登録）

- 管理者は、ほかの管理者が仮登録すると、仮登録のご案内のメールが届きます（7日以内に本登録）。リンクの本登録の画面で、**企業名・お名前（姓・名）**をお確かめのうえ（直せます）、**電話番号**とパスワードを入れて「本登録する」を押し、確認コードを入れると完了です。ふりがな・郵便番号・住所・所属・役職は任意です。期限が切れたときは、登録した管理者に「送り直し」をご依頼ください。
- 最初の1人は、はじめの設定の画面（またはシステムの担当が作る本登録のリンク）で、企業名・お名前・電話・メールアドレス・パスワードをまとめて入れます。
- 本登録のあとで足りない項目が出たとき（古い登録の方など）は、「足りない項目」の画面が出ます。入れるまで、ほかの画面は開けません。
- あとから、右上のお名前 →「アカウント」の「基本」で直せます（企業名もここで直せます）。必須の欄（企業名・お名前・電話番号）は空にできません。入れた内容を見るだけなら、「基本」の上の「登録情報を見る」を開きます（入力欄のない画面です。「編集する」でアカウントに戻れます）。企業名を入れると、ご自分が送る案内メール・一斉送信・テストメール・仮登録のご案内の差出人の名前と署名が企業名になります。通知などの自動のメールは、設定の「運営の名前」のままです。本登録が済んだ方のメールアドレスは、画面からは変えられません。
- 本登録が済むと、ダッシュボードが開きます。
- まだ SES・エンジニア・案件が1つもないときは、ダッシュボードのいちばん上に「**PARK をはじめましょう**」が出ます。「ほかの管理者を登録する（任意）」「SES を仮登録して、SES にご案内を送る」「エンジニアを登録する（SES を選んでから）」（SES の一覧が開きます）「案件を登録する」の順に、ボタンから進めます。済んだ手順には「済み」が付きます。SES・エンジニア・案件のどれかが入ると、このカードは出なくなります。
- ダッシュボードの「**登録の状況**」には、管理者と SES のご担当者が、参加中・仮登録（いつまで）・仮登録（期限切れ）・停止のどれかで並びます（担当者がまだいない SES は「担当者が未登録」。退会済の人は出ません。担当者が全員退会済の SES も「担当者が未登録」に出ます）。仮登録の行には「**送り直し**」、SES の行には「開く」が出ます。

### ログイン中の立場の帯

- 画面の上（メニューの下）に、青い帯で「**管理者としてログインしています：お名前**」と出ます。管理者の画面だとひと目でわかるようにするためです。確認コードを入れる前の画面や、印刷用の画面には出ません。

### 最初の設定

右上のメニューの「設定」で、次を確かめます。

| 項目 | 中身 |
|---|---|
| 初期費用（%） | 成約した月に1回いただく割合（今は 7%。仮） |
| 月額費用（%） | 契約が続く間、毎月いただく割合（今は 3%。仮） |
| 月額は稼働の何か月目から | 1か月目から／2か月目から（今は2か月目から） |
| 消費税（%） | 請求書の消費税 |
| 配信候補に出す最低点 | マッチングの候補に出す点数（今は40点） |

管理者を増やすときは、上のメニューの「管理者」で「管理者を登録」を押し、別の画面で**企業名・氏名（姓・名の2つの欄）・メールアドレスの4つ**（すべて必須）を入れて「仮登録してメールを送る」を押します（宛名は「企業名 氏名 様」になります）。電話番号・郵便番号・住所・所属・役職などは、ご本人が本登録で入れます（管理者は、仮登録のときには入れられません）。本登録が済むと「参加中」になり、管理者全員に知らせ（メールとベル）が届きます。登録した管理者は、一覧の「**詳細**」で内容（住所は「〒123-4567 住所」の形）を見られ、詳細の「**編集**」で直せます（保存すると詳細に戻ります）。仮登録の間に直せるのは、企業名・氏名・メールアドレスの4つだけです。本登録が済んだ人は、氏名・企業名・所属・役職・電話番号・郵便番号・住所を直せますが、必須の欄（企業名・氏名・電話番号）は空にできません。郵便番号は7桁の数字で、ハイフンはあってもなくてもかまいません（「123-4567」の形で保存されます）。住所は200文字までです。住所は個人の情報なので、見られるのは管理者と、ご本人の「登録情報」だけです。メールアドレスを変えられるのは、仮登録中の他の管理者だけです。変えると、新しいアドレスに仮登録のご案内が送り直されます（古いリンクは使えなくなります）。ご自分・本登録が済んだ人・停止中の人のメールアドレスは変えられません。一覧の「状態」は、本登録がまだの人が「仮登録」（期限が切れていれば「仮登録（期限切れ）」）、済んだ人が「参加中」です。仮登録の人の行の「送り直し」を押すと、新しいリンク（7日間有効）のメールが届きます。間違えて登録したときは、仮登録の行の「取り消し」（確認が出ます）で、行を消せます（本登録が済んだ人には出ません。記録には、名前とメールアドレスを残しません）。心当たりがないと回答があったときは、リンクが無効になり、管理者全員に知らせが届きます。「送り直し」で、また使えるようになります。

- **管理者の停止・再開・退会**：一覧の各行と、詳細の右上に、「停止」（停止中は「再開」）「退会」のボタンがあります（一覧では「詳細」が右端です。退会済の人の行は「詳細」だけです）。状態の列には、参加中・仮登録・停止・退会済のどれかが出ます。
  - ご自分の行にはボタンは出ません。使える管理者がほかにいなくなる停止・退会もできません（断りの文が出ます）。
  - 「停止」：その人がログインできなくなります（再開できます）。仮登録の人を止めると、送ったリンクも使えなくなります。仮登録だった人は、再開したあと、一覧の「送り直し」でご案内を送ります。
  - 「退会」：元に戻せません（記録は残ります）。退会済の人の詳細には、「編集」「送り直し」「取り消し」は出ません。
  - エンジニアを兼ねている人：「停止」するとエンジニアとしても入れなくなります。「退会」にすると、管理者の役割だけが外れ、エンジニアとして入れます。

### メールについて

- PARK は、配信・選考の連絡・仮登録のご案内などをメールでも送ります。送ったメールはすべて「メール」の画面に残り、中身を確かめられます。
- メールの送信の設定が済むまでは、メールは**送らずに保存だけ**します（画面の上に黄色い注意が出ます）。設定のしかたは、システムの README にあります。設定したら「設定」→「テストメールを送る」で確かめます。

### テスト用のダミーデータ

- テストの間、一覧に、メールアドレスが `@park.example` の SES・担当者・エンジニアが並ぶことがあります（SES の会社名の末尾に「（ダミー）」が付きます）。いろいろな状態を見るためのダミーで、ログインはできません。
- ダミーには「送り直し」「承認して仮登録のご案内を送る」を押さないでください（届かないメールが出ます）。
- ダミーの SES に、本物の人を登録しないでください。
- ダミーがいる間は、一斉メールを使わないでください。案件の配信でも、ダミーのエンジニア・SES を選ばないでください（応募まで進むと、片付けのコマンドが守りで止まります）。
- 片付けは、システムの管理者がコマンドで行います。

### 登録できる人と、内容に責任を持つ人

- 登録できるのは、上の立場の人だけです。**管理者**（今は2人）が管理者・SES を登録し、**SES** は自社のエンジニアを登録します（管理者がエンジニアを登録するのは、「SES」の画面でその SES を選んでからです）。
- 上の立場の人が入れた情報も、その項目は**本人が責任を持って登録するもの**です。
  - エンジニアは、ホームの「登録の内容の確認」で中身を確かめ、「確認しました」を押します。確認が済むまで、案件に応募できません。
  - 管理者・SES が中身を書き換えると、本人の確認はやり直しになります。
- エンジニアは、**案件ごとに経歴（経験票）を更新**します。成約すると、本人のホームに「経歴の更新」が出ます。案件が終わったら（契約を「終了」にしたら）、本人にお知らせが届き、もう一度書いてもらいます。


### ホームの「今やること」

ホームのいちばん上に「**今やること**」が出ます。上から順に押して片付ければ、その日の仕事が終わるように並べています。

## 3. SES の管理

- **申し込みの承認**：ダッシュボードの「参加の申し込み」、または「SES」の一覧から会社を開き、「承認する」を押します。仮登録と同じ入力画面に、申し込みの内容が入って出ます。企業正式名称・SES の姓・名・メールをお確かめのうえ、「承認して仮登録のご案内を送る」を押します。SES に仮登録のご案内が届き、申し込んだ方のメールアドレスにも承認のお知らせが届きます（同じアドレスなら1通にまとめます）。申し込みのときの守秘義務の同意は、SES の本登録で取り直します。
- **管理者が登録する（仮登録）**：「SES」→「SES を仮登録」。**企業正式名称・SES の姓・名・メールアドレスの4つだけ**を入れて「仮登録してメールを送る」を押すと、SES に仮登録のご案内（7日以内に本登録）が届きます。会社は「仮登録」の状態になり、SES が本登録（確認コードまで）を済ませると「参加中」になり、管理者全員にメールと知らせが届きます。電話・住所などは、SES が本登録で入れます。
- **仮登録の間にできること**：SES の一覧と詳細に「仮登録」（期限が切れたら「仮登録（期限切れ）」、「心当たりがない」が押されたら「仮登録（心当たりなし）」）と出ます。「**送り直し**」で新しいリンクを7日間出します（前のリンクは使えなくなります）。「**仮登録の内容を直す**」では企業正式名称・SES の姓・名・メールを直せます（同じ行のまま。メールを変えると、新しいアドレスに送り直します）。間違えて登録したときは「**取り消し**」（確認あり）で、仮登録の行を消せます（本登録を始めた方・参加中の会社は取り消せません）。仮登録の会社は、停止できません。
- **会社情報を直す**：SES の詳細の「会社情報」の「編集」（本登録のあと）。別の画面で企業正式名称・SES の姓・名・電話・郵便番号・所在地などを直して「保存する」を押します。必須の項目（企業正式名称・SES の姓名・電話・郵便番号・住所）は空にできません。メールは見るだけです（戻るときは「戻る」）。
- **担当者を増やす**：参加中の SES の詳細の「担当者」の「担当者を登録」（仮登録・停止中などの会社には出ません）。別の画面で**姓・名・メールアドレスの3つ**を入れると、担当者に仮登録のご案内が届き、その会社の SES にも知らせます。電話・守秘義務の同意は、担当者が本登録で入れます。本登録が済む前の行には、「送り直し」「仮登録の内容を直す」（姓・名・メール・所属の SES）「取り消し」が出ます。所属の SES を直せるのは管理者だけで、選べるのは参加中の SES です。
- **SES と担当者の違い**：会社の情報（企業正式名称・SES の姓名・電話・住所）の編集と、担当者の登録・停止・退会ができるのは、SES と管理者だけです。担当者は会社情報を見るだけで、エンジニアの登録・停止・退会はできます。SES は、交代のあとでなければ停止・退会にできません。
- **SES の交代**：SES の詳細の「SES の交代」で、**本登録が済んだ担当者**から選んで「SES にする」を押します（前の SES は担当者になります。SES の人は交代できません）。担当者がいない会社では、「次の SES を仮登録する」で姓・名・メールを入れます。その方の本登録が済むと SES が入れ替わります（それまでは今の SES のままです）。
- **担当者ごとの停止・再開・退会**：SES の詳細の「担当者」の表の、その人の行に「停止」（停止中は「再開」）「退会」「詳細」のボタンがあります。退会済の人の行は「詳細」だけです（SES の担当者も、自社のほかの担当者を停止・再開・退会にできます（詳細の画面は管理者だけ）。ご自身の行にはボタンは出ません）。状態の列には、参加中・仮登録・停止・退会済のどれかが出ます。
  - 「停止」：その人だけがログインできなくなります（再開できます）。仮登録の人を止めると、送ったリンクも使えなくなります。止めた人の行には「再開」「退会」「詳細」が出ます。仮登録だった人を再開したときは、「担当者」の表のその人の行の「送り直し」で、ご案内を送り直します。
  - 「退会」：その人は「退会済」になり、ログインできません。**元に戻すボタンはありません**（記録は残ります）。退会済の人の行には、「詳細」のほかのボタンは出ません。
  - その会社で使える担当者が1人だけのときは、その人は停止も退会もできません（断りの文が出ます）。会社ごと止めるときは、下の会社ごとの「停止」「退会」を使います。使える担当者がいない会社（参加中なのに全員が停止か退会済のとき）には、SES の詳細に「使える担当者がいません」の注意が出ます（止めている人がいれば「再開」、いなければ「登録」を勧めます）。
  - 稼働中の契約があっても、担当者は止めたり退会にしたりできます（契約は会社のものです）。
  - 停止中や退会済の人のメールアドレスでは、「担当者を登録」で登録できません（管理者には、理由を別々の文で出します）。
- **担当者の詳細**：行の「詳細」で、状態・SES（会社名）・氏名・ふりがな・メールアドレス・電話番号・所属・役職・エンジニア兼任（ありならエンジニアの詳細へ）・最終ログイン・登録日が見られます。この画面の右上でも停止・再開・退会ができ、押すとこの画面に戻ります（エンジニア兼任の人を退会にしたときは SES の詳細に戻ります）。直すところはご本人の「アカウント」です（管理者の画面からは直せません）。「SES の詳細に戻る」で戻ります。
- **会社ごとの停止・再開**：SES の詳細の「会社情報」の「停止」。その SES の担当者全員がログインできなくなり、エンジニアは配信の候補に出なくなります（担当者ごとの停止は、その人だけです）。停止中は「再開」が出て、押すと参加中に戻ります（仮登録のご案内は送りません）。「承認する」は、申込中の SES だけに出ます。参加中の SES だけを停止できます（仮登録・申込中の SES は停止できません）。
- **SES の一覧から**：「SES」の一覧の各行にも、「停止」（停止中は「再開」）「退会」「詳細」のボタンがあります（申込中の行は「退会」「詳細」、退会済の行は「詳細」だけ）。押すと、一覧に戻ります。
- **退会**：SES の詳細の「退会」。その SES と所属エンジニア全員が「退会済」になり、ログインできなくなります。記録（案件・応募・契約・請求）は消えず、元に戻すボタンはありません。稼働中の契約があるときは退会にできません（先に契約を終了します）。エンジニアだけを退会にするときは、エンジニアの詳細の「退会」、または SES の詳細の「エンジニア」の表のその行の「退会」です。
- 詳細の画面の下には、一覧に戻るボタンがあります。「詳細」「編集」のボタンは青色です。
- 「管理者のメモ」は SES には見えません。

## 4. エンジニアの管理

- 「エンジニア」の一覧で、名前・スキル・SES で探せます。状態（待機中・提案中・稼働中・休止）で絞り込めます。停止しているエンジニアには、状態の横に「停止中」と出ます。
- **停止・再開・退会**：エンジニアの詳細の「基本情報」の右上に、「停止」「退会」「編集」の順にボタンが並びます（所属の SES の担当者も、自社のエンジニアに同じ操作ができます）。
  - 「停止」：本人がログインできなくなり、案件の配信の候補（おすすめ・案件メールの候補・配信）に出なくなり、応募もできなくなります。稼働中の契約と選考中の応募は、そのまま残ります（確認の文に出ます）。停止中は「再開」で元に戻せます。停止中は「送り直し」も出ません。メールアドレスの無いエンジニアも停止できます。停止・再開すると、相手側（管理者が押したら所属の SES、SES が押したら管理者）に画面のお知らせが出ます（メールは送りません。本人には何も送りません）。
  - 「退会」：元に戻せません（記録は残ります）。停止中のエンジニアも退会にできます。稼働中の契約があるときは退会にできません（先に契約を終了します）。退会済のエンジニアには、停止・再開・退会のボタンは出ません。
  - 「エンジニア」の一覧（SES の担当者は自社の「エンジニア」の一覧）の各行にも、「停止」（停止中は「再開」）「退会」「詳細」のボタンがあります。押すと、絞り込み（探した文字・状態など）をそのままにして一覧に戻ります。退会済の人は「詳細」だけです。
  - SES の詳細の「エンジニア」の表でも、行ごとに「停止」（停止中は「再開」）「退会」「詳細」を押せます（押すと SES の詳細に戻ります。退会済の人は「詳細」だけ。停止中の人の状態には「停止中」の札が出ます）。
- 管理者がエンジニアを登録するのは、「SES」の画面でその SES の「詳細」を開き、「エンジニア」の欄の「エンジニアを登録」を押すときです（このエンジニアの一覧には登録のボタンはありません）。所属はその SES に決まっていて、画面では読むだけです。入れるのは、**姓・名・メールアドレスの3つ**だけです（メールアドレスは必須）。登録すると、本人に仮登録のご案内がその場で届き、所属の SES にも知らせます。ふりがな・電話・郵便番号・住所・同意は、本人が本登録で入れます。本登録が済むまでは「仮登録」と出て、技術・住所などは管理者も入れられません（直せるのは姓・名・メール・所属の SES です）。「送り直し」「取り消し」は、エンジニアの一覧・詳細・SES の詳細の表にあります。
- **所属の SES を変える**：エンジニアの「編集」の下の「所属」のカードで、変更先（管理者の直属、または参加中の SES）を選び、「所属を変える」を押します（確認の窓で「OK」）。変えられるのは、退会済でなく、仮登録中でなく、SES 担当者・管理者を兼ねていなくて、稼働中の契約と選考中の応募が無い人です（変えられないときは理由が出ます）。**仮登録中の人は、ここではなく「仮登録の内容を直す」（氏名・メール・所属）から変えます**。停止中の人は、管理者だけが変えられます。変えると、元の会社の SES・担当者にはその人が見えなくなり、新しい会社に見えるようになります。過去の応募・契約・請求の記録は、元の会社のまま残ります。元の会社・新しい会社（直属なら管理者）・本人に画面のお知らせが出て、本人にはメールも届きます。SES・担当者が自社のエンジニアを移したときも、管理者にお知らせが届きます。
- **管理者の直属のエンジニア**：新しく直属の人を登録する入口はありません（エンジニアは、必ず SES を選んでから登録します）。今いる直属の人は、これまでどおり一覧に「直属」の印で出ます（直属の人がいるときだけ、「直属だけ」のボタンで絞り込めます）。応募・選考・成約は、ほかのエンジニアと同じ画面で進めます。知らせ（面談・成約など）は、SES の代わりに管理者全員に届きます。SES の担当者には、直属のエンジニアの名前・詳細は見えません（案件メールの候補にはイニシャルで出ます）。直属は SES の一覧・数・分析には入らず、請求書も作りません。
- エンジニアの詳細の画面で、プロフィール・スキル・経験票を見たり直したりできます。右側に**スキルシートの完成度**と、良くするための指摘が出ます。仮登録中のエンジニアのスキル・経験票は直せません。直すと、ご本人の「確認しました」がやり直しになります。
- スキルは**チェック式**です。経験のある項目にチェックを入れ、年数を4段階（1年未満・1年以上・3年以上・5年以上）から選びます（選ばなければ「経験あり」）。一覧に無いものは「その他」に名前を書きます。言語・データベース・OS は、子（Laravel など）を選ぶと親（PHP など）にも自動でチェックが入り、親を外すと子も外れます。レベル・得意・ひとことはありません。そのほか、**業務経験**・**業界**・**業務領域**（それぞれ当てはまるものすべて。年数なし）と、役割で PM・PL を選んだときだけ出る「PM/PLご経験者の方へ」の3問（それぞれ1つ選ぶ）があります。PM・PL を外して保存すると、3問の回答は消えます。業界・PM/PL の回答は、案件の点数や一覧のスキルの列・検索には使いません。業務経験・業務領域は、案件の「必須の業務」「尚可の業務」と突き合わせて、案件の点数（マッチング・案内メールの候補の順・配信の点数）に使います（一覧のスキルの列・検索には出ません）。項目の表が変わって、前に保存した項目が表から無くなったときは、編集画面の下に「今の表に無い項目」が出ます（チェックを外して保存すると消えます）。
- **管理者の印**：管理をしながら、自分もエンジニアとして入る人に付けます（一覧の下の「切り替え」）。マッチングの候補に「管理者」と出ます。配信・選考はすべて記録に残るので、公平に扱っていることを後から示せます。

### エンジニアを兼ねる（兼任ログイン）

同じメールアドレスで、エンジニアと、SES 担当者・管理者を兼ねられます（アカウントは増えません）。

- **管理者が自分もエンジニアとして入る**：「SES」の画面でその SES（直属でない、参加中の SES）を選び、「エンジニアを登録」で、メールアドレスに**ご自分のメールアドレス**を入れて登録します。仮登録のご案内は出ず、運営者の印が自動で付きます。ほかの管理者のメールアドレスを入れたときは、その人にお知らせが届きます。
- **SES の担当者を、その SES のエンジニアとして登録する**：その SES の担当者のメールアドレスで、その SES のエンジニアを登録すると、兼任になります（本人にお知らせが届きます）。あとからメールアドレスを入れたエンジニアは、詳細の「送り直し」で兼任になります。兼ねられるのは**同じ SES のエンジニア**だけです。
- **逆向き**：SES の詳細の「担当者を登録」で、その SES のエンジニアのメールアドレスを入れると、SES 担当者の役割が足されます。「管理者を登録」でエンジニアのメールアドレスを入れると、管理者の役割が足されます（企業名などは、この画面の値）。仮登録のご案内は出ません。役割を足せるのは、本登録が済んだ方だけです（仮登録中の方のアドレスは断ります）。次にその立場で入るときに、その立場の足りない項目と同意を取ります。
- 次は今までどおり断られます：他社の担当者やエンジニアのアドレス、管理者と SES 担当者を兼ねる形になるもの、停止中・退会済の人、すでに別のエンジニアと兼任している人。SES が管理者のメールアドレスでエンジニアを登録することもできません。
- **ログインのとき**：パスワードと確認コードのあと、「どの立場で入りますか」の画面で立場を選びます。入ったあとは変えられません（ログアウトして入り直します）。立場ごとに、見える範囲は混ざりません（エンジニアの立場では、本人の分だけです）。お知らせとメールも立場ごとに分かれます（メールの頭に「【管理者あて】」などが付きます）。
- **管理者が自分のエンジニアの分を進めるとき**：管理者の立場で、自分のエンジニアに関わる操作（登録内容の編集・配信・応募・選考・面談の結果・契約・延長・終了）をすると、記録に「［本人］」が付き、応募・契約の画面に「管理者ご本人の応募」の札が出ます。公平性のため、運営者の印と合わせて見返せます。管理者の立場で直すと、本人の「確認しました」は外れます。エンジニアとして入り直して確認します。
- **管理者の画面の見え方**：ホームの「登録の状況」に「SES（エンジニア兼任）」「管理者（エンジニア兼任）」、SES の詳細の「担当者」の表と担当者の詳細、管理者の一覧に「エンジニア兼任」の札、エンジニアの詳細の「アカウント」に「SES 担当者と兼任」「管理者と兼任」と出ます。SES の画面には、管理者との兼任は出ません。
- **停止と退会**：
  - エンジニアを停止すると、エンジニアの立場だけ入れなくなります（もう一方は使えます。再開で戻ります）。SES がエンジニアを停止・退会にしても、管理者を兼ねる人の管理者のログインは止まりません。
  - エンジニアを退会にすると、兼任がはずれます（SES 担当者・管理者としては入れます）。
  - 管理者を兼ねる人も同じです。管理者を停止すると、エンジニアとしても入れません。管理者を退会にすると、管理者の役割だけがはずれ、エンジニアとして入れます。
  - SES 担当者を退会にすると、担当者の役割だけがはずれ、エンジニアとして入れます。SES 担当者を停止すると、ログインそのものが止まります（エンジニアとしても入れません）。
  - 会社を停止（または未承認）にすると、兼任の担当者はエンジニアとしてだけ入れます。会社を退会にすると全員止まります（管理者を兼ねる人は、管理者としてだけ入れます）。
- 今ある別々のアカウント（管理者用とエンジニア用など）は、自動ではまとめません。

### 詳しいプロフィールと書類（データ領域）

- エンジニアの詳細の画面の「詳しいプロフィール」で、履歴書・業務経歴書に載せる項目（生年月日・住所・電話・最寄りの路線と徒歩・最終学歴・職務概要・希望業務・語学・学歴/職歴・資格・アピール・本人希望）を入れます。
- 経験票の各案件には、「使った技術」のほかに「機種・OS・ツール」「言語」「DB」「並び順（業務経歴書の No.）」を入れられます。マッチングでは、これらの欄の技術もすべて数えます（「PHP(Laravel)」のような書き方は PHP と Laravel に分けて数えます）。
- 詳細の画面の右上の「データ領域」で、最新の**履歴書**と**業務経歴書**（名前を伏せた版も）を Excel で書き出して保存できます。書き出すたびに版が残り、いつでもダウンロードできます。手持ちの PDF などもアップロードできます（10MB まで）。
- 郵便番号は7桁の数字で入れます（例：123-4567）。住所を見られるのは、本人・所属の SES・管理者だけです（ほかの SES・ほかのエンジニアには見えません）。SES の会社の郵便番号・所在地も、その SES の担当者と管理者だけが見られます。
- 書類を見られるのは、本人・所属の SES・管理者だけです。ダウンロードと削除は、操作の記録に残ります。

### 技術マスタ（技術の細かい分類）

- 「設定」→「技術マスタ」（またはエンジニアの一覧の「技術マスタ」）で開きます。案件メールの技術と、エンジニアのスキルを、同じ「正式な名前」にそろえて突き合わせるための辞書です。
- 分類は、言語・フレームワーク・DB・OS・クラウド・インフラ／ミドルウェア・ツール・工程／開発手法・業種／業務・役割に分かれています。別名（例：Postgres・psql → PostgreSQL、SQLServer → SQL Server）も同じ技術として扱います。
- 案件を登録したとき、必須・尚可にマスタに無い技術があると、**自動でマスタに追加**し、管理者に知らせます。エンジニアのスキルに無い言葉が入ったときも同じです。追加されたものは「確認待ち」になるので、分類と別名を確かめて「確認済みにする」を押してください。同じ技術の言い換えなら「統合」で、正式な技術の別名にまとめます。
- 案件メールの取り込みでは、本文に出てくる技術もマスタから探し、必須に無いものを「尚可」に入れます。登録の前に確かめてください。
- 一覧の「**使っている人（スキル表・経歴）**」は、スキルのチェック（その他に書いた名前を含む）に入れている人と、経験票（経歴）に書いている人の両方を数えます。同じ人は1回です。
- 「**統合**」を押すと、経験票から作った技術の索引が、まとめ先の技術に付け替わります。スキルのチェックは項目の名前で持っているので、統合の影響を受けません。その他に書かれた言葉は、確認待ちで技術マスタに足されます。途中で失敗したときは、全部元に戻ります。
- 言葉を「追加」したときと、「確認済みにする」（保存）を押したときは、全部の経験票の技術の索引が作り直されます。あとから足した言葉や、変えた分類・別名が、「経歴から」の月数に反映されます。確認済みの言葉だけが、エンジニアの入力欄の候補に出ます。

### スキルシートのやり取り

- エンジニアから「スキルシートを見てほしい」と届くと、通知とメールで知らせが来ます。「やり取り」の画面、またはダッシュボードの「未読のメッセージ」から開いて返事をします。
- スキルシートは、**事実だけ**で作ります。成果は数字で（例：処理時間を30%短縮）、担当した工程をはっきり書いてもらいます。盛った内容は、面談や配属後のトラブルの元になります。

### 連絡メール（エンジニアにメールを送る）

案件に結び付かない、自由な件名・本文のメールを、エンジニアに送れます（案件の「案内メール」とは別です）。

- **送り方**：「エンジニア」の一覧で、送りたい人の行にチェックを入れ、「選んだ人にメールを送る」を押します（「全選択」もあります）。仮登録・停止中・退会の人には送れないので、チェックが出ません。1人だけに送るときは、エンジニアの詳細の「メールを送る」が早道です。
- **送れる相手**：どの会社のエンジニアにも送れます（管理者の直属の人も）。1回に 50 人まで、件名 100 文字・本文 5000 文字までです。送る前に、ブラウザの確かめ（「n名に送ります」）が出ます。
- **届き方**：選んだ人それぞれに、1通ずつ届きます（ほかの宛先は見えません）。本文の頭に宛名、うしろに「どこから送ったか」の数行が自動で付きます。本人には PARK の画面のお知らせも届きます。
- **返信先**：管理者から送ったメールには、返信先を付けていません（あなた個人のアドレスは相手に見えません）。返信は PARK の共通の差出人アドレスに届きます。
- **エンジニアから届く連絡メール**：エンジニアは、所属の会社の担当者に連絡メールを送れます。管理者の直属のエンジニアからは、管理者に届きます（ナビの「連絡メール」の「受け取った」で読めます）。
- **「連絡メール」の画面**：「受け取った」「送った」のほか、管理者には「**すべて**」があり、全員の連絡メールを見られます（宛先ごとに、送れたかどうかも出ます）。
- 「やり取り」（スキルシートの相談。PARK の画面の中だけ）は今までどおりです。連絡メールは、受け取った人にメールで届く点が違います。

## 5. 案件の登録

1. 「案件」→「案件を登録」。
2. 届いた案件メールの本文を「案件メールから取り込む」に貼り付けて「取り込む」を押すと、案件名・金額・必須スキル・場所・開始などが自動で入ります（PC の中で処理し、外部のサービスには送りません）。
3. 抜けているところ・違うところを直して「登録する」。取り込みでは、必須・尚可の文から**業務経験・業務領域**（進捗・課題管理、英語・海外、経理・財務など）も拾って、案件票の「業務経験・業務領域（必須・尚可）」に選んでおきます。項目ごとに「—／必須／尚可」を選べるので、確かめて直してください（取り込みの知らせに、拾った名前が出ます）。

| 項目 | 書き方 |
|---|---|
| 元請け | 伏せ字でかまいません（例：SH-A 社）。元請けの名前は外に出しません |
| 金額 | SES が元請けから受け取る月額（万円）。成功報酬の基準になります |
| 必須・尚可スキル | 「、」で区切ります（例：Java、Spring Boot、Oracle）。マッチングに使います |
| 必須・尚可の業務 | 「業務経験・業務領域（必須・尚可）」で、項目ごとに「—／必須／尚可」を選びます。エンジニアの業務経験・業務領域のチェックと突き合わせて、点数に使います（選ばなければ、点数は今までどおり） |
| 経験年数・働き方・開始 | マッチングの点数に使います |

### 手元の AI による必須・尚可の読み直し

- 取り込みの読み方（規則）は、見出しの書き方がいろいろなメールでも読めるようになりましたが、見ていないメールでは 6 割前後です。そこで、本文のある案件を**登録すると**、手元の PC の AI が必須・尚可を読み直します（1件 1分ほど。合言葉が設定されているときだけ。取り込みの画面では動きません）。AI が止まっていても、登録も案内も今までどおりできます。
- 結果は、案件の画面の「**AI の読み直し**」の欄に出ます（見えるのは、その案件を直せる人だけ。エンジニアには出ません）。AI の各項目は本文と突き合わせ、本文にそのままあれば「そのまま」、近い行があれば本文の文に戻し、無ければ「本文に無い言い方」の印が付きます。
- **自動で AI の結果にする**のは、次の全部がそろったときだけです：規則と必須・尚可の行数が同じ／「本文に無い言い方」が無い／人が直していない（登録の前も後も）／案内・案内メール・応募がまだ無い／募集中か下書き／本文が頼んだときと同じ。差し替えるのは必須・尚可・必須の業務・尚可の業務の4つだけです。
- 自動で入れないときは、違いの表（今と AI を並べ、「AI だけ」「今だけ」を示します）が出て、**登録した人**に知らせが届きます（メールは送りません）。内容を確かめて「**AI の結果を使う**」か「**今のままにする**」を押してください。人が直したか、本文を変えた案件で使うと、直した必須・尚可・業務も置き換わります。AI が必須も尚可も読めなかったときは、自動では入れず、確かめてもらいます。本文を変えたあとは、前の結果は使えません（表は消え、「もう一度頼む」で頼み直します）。
- AI も規則と同じ読み方だったときは「AI も同じ読み方でした」とだけ出ます。**案内のあとは、AI の結果を自動では入れません**（エンジニアに届いた内容が、知らないうちに変わらないようにするため）。
- 保存済みの案件には、案件の画面の「AI に読み直してもらう」で1件ずつ頼めます。頼んだ仕事は「設定」の「AI の仕事」の一覧に出て、押すとその案件の画面へ行けます。

SES が登録した案件は、管理者に通知が来ます。SES は、自分で登録した案件を、案件の画面の「エンジニアに案内する」から、自社のエンジニア（とグループのほかの人）にメールで案内できます（流れは SES 向けのマニュアル）。管理者も同じ画面から、グループ全体の人に案内メールを送れます。

## 6. マッチングと案内

1. 案件を開き、右側の「**エンジニアに案内する**」を押します。**エンジニア検索**の画面が開きます（流れは SES 向けのマニュアルの「エンジニアにメールで案内する」と同じ。管理者はグループ全体の人から選べます）。
   - 左に元のメール、右にメールから抜き出した必須・尚可が出ます。「外す」にチェックを入れるか、欄に書いて足して、「エンジニアを検索」を押します（この検索にだけ使います。案件の必須・尚可は変わりません）。
   - 一覧には、必須の4分の3以上（4項目なら3つ）に当たった人が並びます。**直属の会社の人が上、ほかの会社の人が下**で、それぞれ経験の長い人が上です。名前はすべて見えます。「一覧に足す」で、条件に届かなかった人も足せます。
   - 名前を押すと詳細で、○×・個別メッセージ・「ご検討ください」の確認メモ（メールには入りません）・メールの見本が見られます。「エンジニアへメールを送信」で、チェックした人に送ります。メールの本文は直せません（全員へのメッセージ・個別メッセージで言いたいことを足します）。
2. 点数は、必須スキル（いちばん重い。必須の業務も同じ重さで数えます）・尚可スキル（尚可の業務も数えます）・経験年数・単価・開始日・働き方から計算します。経験票で使った技術も数えます。
3. 案内メールには「応募したい／質問がある／見送る」のリンクが付きます。押されると記録され、送った人に知らせが届きます。

**最終の判断は人がします。** 足りない点が大きい人に送らないことも、成約率を上げます（ミスマッチの応募が減り、元請けからの信頼も上がります）。

SES が持ち込んでいない案件（管理者が登録した案件・ほかの SES の案件）には、SES から「推薦」が届くことがあります。名前を伏せて知らせが来るので、「グループのほかの人」から選んで案内します。

### AI の仕事の箱

- 面談スクリプトの言い回しを整える、経歴書（Excel・Word・テキスト）から経験票の下書きを作る、の2つを AI に頼めます（面談の画面の「AI に頼む」、エンジニアの書類の「AI で経験票の下書き」）。
- AI は**手元の PC**（FOCUS）で動きます。PARK は仕事を箱に入れるだけで、手元の PC の AI が取りに来て、下書きを返します。案件や個人の情報は、手元の PC の外に出ません。PC が止まっているあいだは、仕事は順番待ちのままです。
- できた下書きは、人が中身を確かめて「採用する」「経験票に足す」を押したときだけ使われます。
- 「AI」の画面で、仕事の一覧と、AI が最後に取りに来た日時を見られます。

## 7. 選考を進める

「応募・選考」の画面に、段階ごとのボード（応募 → 書類提出 → 書類通過 → 面談調整 → 面談済み）が出ます。ダッシュボードの「いま管理者がやること」にも出ます。カードを開くと、その応募の画面になります。

1. **応募が来たら**：応募の画面で、本人が確かめた条件（開始・金額・働き方、気になること）を見ます。「この案件に合わせたスキルシート」（名前を伏せた版。案件に関係する経験が上に来て、合う技術が強調されます）を印刷・PDF にして元請けに出し、「スキルシートを提出した」を押します。
2. **書類が通ったら**：「書類が通過した」を押します。
3. **面談依頼が来たら**：日時と場所（URL）、依頼の内容（先方が確かめたいこと）を入れて「面談依頼を記録する」。**面談スクリプト**（想定質問と答え方）が自動でできます。最初に案件とスキルの突き合わせ（合う点・足りない点）、続けて先方が確かめたいことが入ります（自己紹介・直近の案件・必須スキルごとの質問・条件・逆質問など、本人の経験票から答え方のヒント付き）。面談の画面で中身を確かめ、必要なら直してください。本人と SES に知らせが届きます。
4. **面談のあと**：面談の画面の「結果を記録」で、通過／見送りと、元請けからの印象を残します。
5. **成約**：応募の画面の「成約を記録」で、金額・開始日・契約の終わり（空なら3か月）を入れます。案件は募集人数に達すると「充足」になります。
6. **見送り**：応募の画面の下で、理由を選び、1行で詳しく書いて「見送りにする」。理由は「分析」で集計されます。

気づいたことは、応募の画面の右の「メモ・フィードバックを残す」に書きます。

SES も、自社の応募について、ここの 1〜6（面談依頼の記録・スクリプトの手直し・結果・成約・見送り）を自分で進められます。SES が面談依頼を記録すると、管理者に知らせが届きます。

## 8. 契約・成約後のフォロー

- 「契約」の一覧で、稼働中・終了の契約を見られます。ダッシュボードに「1か月以内に終わる契約」が出ます。
- **延長**：契約の画面で月数を入れて「延長を記録」。
- **終了**：終了日と理由を入れて「終了にする」。本人に「経歴を更新してください」とお知らせが届きます。
- **フォロー**：配属後の最初の1か月に、本人に調子と困りごとを聞き、契約の画面に記録します（本人もホームから記入できます）。調子が悪い・困りごとがあると、管理者に通知が来ます。

## 9. 請求

1. 月が終わったら、「請求」→ 対象の月を選んで「この月の請求書（下書き）を作る」。SES ごとに、初期費用（稼働開始の月）と月額費用を計算します。
2. 請求書を開いて中身を確かめ、「発行して SES に知らせる」。SES に通知とメールが届き、SES の画面でも見られるようになります。
3. 入金を確かめたら「入金を記録」。

下書きは何度でも作り直せます（発行済みのものは変わりません）。請求書は「印刷・PDF に保存」で PDF にできます。

## 10. メールの一斉配信

「メール」→「一斉配信」で、参加中の SES の担当者全員・エンジニア全員・待機中のエンジニアなどに、お知らせを送れます。宛名（◯◯ 様）は自動で入ります。

## 11. 分析

「分析」の画面で、次を見られます。件数が少ないうちは率が大きくぶれるので、1件の結果で判断しないでください。

- 配信 → 応募の率、応募 → 成約の率、応募から成約までの日数、延長した契約の割合
- 応募 → 成約のファネル（どの段階で落ちているか）
- SES ごとの成約率
- 見送りの理由、エンジニアが案件を見送った理由
- 月ごとの成功報酬（計算上）

### ID（番号）と「ID で探す」

人・会社・案件・応募・契約・請求書には、口で言いやすい番号（ID）が付いています。「C-12 の件」のように、電話やメールで話が通じます。

| 相手 | ID の形（例） |
|---|---|
| 管理者 | `A-000001` |
| SES の担当者 | `T-000003` |
| 会社（SES・直属） | `S-000002` |
| エンジニア | `E-000015` |
| 案件 | `C-000012` |
| 応募 | `AP-000020` |
| 契約 | `CT-000004` |
| 請求書 | `IV-000007`（発行したときに付きます。下書きには付きません） |

- ID は作った順の通し番号で、一度付いたら変わりません（所属の変更・停止・退会・兼任の付け外しでも同じです）。役割を足した人（例：エンジニアに管理者の役割を足す）には、その役割の ID が付き、役割を外して戻しても同じ ID です。
- ID は、管理者の一覧・詳細、案件・応募・契約・請求書の画面、お知らせとメールの題の終わり（`［C-000012］` の形）に出ます。請求書には「請求書番号」として出ます。
- 画面の上の帯の「ID で探す」に ID を入れて「探す」を押すと、その詳細が開きます。全角・小文字・ゼロの省略（`c12` や `Ｃ－１２`）でも探せます。見つからないときと、見られないときは、同じ文が出ます。エンジニアの一覧では、検索の欄にも ID を入れられます。
- **書き出す書類（履歴書・業務経歴書・スキルシートの印刷。名前を伏せた版も）には、ID は入りません。**
- 付け漏れがないかは、`park:status` の「ID の無い行」で見られます（ふだんは 0。0 でなければ、`park:fill-ids` で数え、`park:fill-ids --apply` で付けます）。

## 12. 困ったとき

| こんなとき | すること |
|---|---|
| 確認コードのメールが届かない人がいる | 迷惑メールのフォルダを見てもらいます。メールアドレスが使えなくなったときは、正しいメールアドレスに直します |
| パスワードを忘れた人がいる | ログインの画面の「パスワードを忘れたとき」から、本人が再設定できます |
| 仮登録のメールの期限（7日）が切れた | エンジニアの一覧・詳細、または SES の詳細・「担当者」の表の「送り直し」で送り直します |
| メールが届かないと言われた | 「メール」の画面で、その人宛てのメールの状態を見ます（失敗ならエラーが出ます） |
| 誰が何をしたか確かめたい | 「設定」→「記録を見る」。配信・選考・請求・設定の変更などがすべて残っています |

## 13. 守ること

- 案件の内容・元請けの名前・エンジニアの個人情報を、外部のサービス（ChatGPT など）に渡さない。
- スキルシートは事実だけで作る。盛らない。
- エンジニアの個人情報は、本人の同意（本登録のときに取ります）の範囲で使う。
