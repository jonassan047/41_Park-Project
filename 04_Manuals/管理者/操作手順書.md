# PARK 操作手順書（管理者向け）

PARK を管理する人が、**ログイン → 設定 → メールの処理**を、この順に進めるための手順書です。画面ごとの細かい説明は「管理者マニュアル」にあります。

## 1. 初めてのログイン

ほかの管理者が上のメニューの「管理者」→「管理者を登録」で**仮登録**すると、**仮登録のご案内**のメールが届きます（最初の1人は、システムの担当が本登録のリンクを作ります）。7日以内に**本登録**をします。

1. 仮登録のご案内のメールのリンクを開きます（期限は7日）。
2. 「本登録」の画面で、**企業名・お名前（姓・名）**をお確かめください（違っていれば直せます）。**電話番号**を入れ、パスワード（8文字以上）を2回入れて「**本登録する**」を押します。ふりがな・郵便番号・住所・所属・役職は任意です。心当たりがないときは、画面の「心当たりがない」を押します（リンクが無効になり、登録した方に知らせが届きます）。
3. 登録のメールアドレスに、**確認コード**のメール（件名：確認コード 123456）が届きます。6桁のコードを入れて「ログイン」を押します（10分間有効）。コードを入れると本登録が完了します。
4. 期限（7日）が切れたり、リンクが使えなくなったときは、登録した管理者に「送り直し」をご依頼ください。
5. ダッシュボードが開けば、ログインは完了です。画面の上に、青い帯で「管理者としてログインしています」と出ています。まだ SES・エンジニア・案件がないときは、いちばん上に「**PARK をはじめましょう**」が出ます。ボタンを上から順に押して進めます（済んだ手順には「済み」が付きます）。
6. ダッシュボードの「**登録の状況**」で、管理者と SES のご担当者の状態（参加中・仮登録・仮登録（期限切れ）・停止・担当者が未登録。退会済の人は出ません）を確かめられます。仮登録の行には「**送り直し**」が出ます。

## 2. 2回目からのログイン

1. https://www.jona.jp/park/login を開きます。
2. メールアドレスとパスワードを入れて「ログイン」。前にログインしたことがあれば、メールアドレスは最初から入っています。
3. 届いた確認コードの6桁を入れて「ログイン」。

| こんなとき | すること |
|---|---|
| 確認コードが届かない | 迷惑メールのフォルダを見ます。無ければ画面の「コードを送り直す」 |
| 10分すぎてしまった・まちがえすぎた | 確認コードの画面を開き直すと、新しいコードが自動で届きます（まちがえすぎたときは、1分ほどたってから開き直します）。新しいメールの6桁を入れます |
| パスワードを忘れた | ログインの画面の「パスワードを忘れたとき」から、再設定のメールを受け取ります |

## 3. 最初の設定

### 3-1. アカウントの設定

1. 右上のお名前 →「**アカウント**」を開きます。
2. 「基本」の上の「**登録情報を見る**」を押すと、今の登録内容を見るだけの画面が開きます（「編集する」でアカウントに戻れます）。「基本」では、氏名（姓・名）・ふりがな（姓・名）・企業名・所属・役職・電話を確かめます（企業名は、あとからここで直せます。入れておくと、ご自分が送る案内メール・一斉送信・テストメール・仮登録のご案内の差出人の名前と署名が企業名になります。画面の上の「管理者（企業名）としてログインしています」にも出ます）。「**メールでも通知を受け取る**」には、チェックを入れたままにします（外すと、申し込み・応募・面談依頼などの知らせがメールで届かず、画面のベルだけになります）。「保存する」を押します。
3. パスワードを変えるときは、「パスワードの変更」で変えます（「変更する」を押します）。

### 3-2. PARK 全体の設定

上のメニューの「**設定**」を開きます。

| 項目 | すること |
|---|---|
| サービス名 | 「PARK」になっているか確かめる（メールの送り元・画面の名前に出ます） |
| 運営の名前（企業名が無いとき・自動のメールの署名） | 「PARK 管理者」など、メールの最後に出る名前。企業名を入れた管理者が自分で送るメールは企業名になります。通知・確認コード・パスワード再設定などの自動のメールは、いつもこの名前です |
| 初期費用・月額費用（%）・月額は何か月目から・消費税 | 成功報酬の計算に使う。決まったら直す |
| 配信候補に出す最低点 | マッチングの候補に出す点数（今は40点） |

変えたら「保存する」。

続けて、同じ画面の「メールの送信」で、「設定済み」と出ているか見ます。「**テストメールを送る**」を押し、自分にテストメールが届くことを確かめます。

管理者を増やすときは、上のメニューの「管理者」を開き、「**管理者を登録**」を押します。別の画面で、**企業名・氏名（姓・名）・メールアドレスの4つ**（すべて必須）を入れて「**仮登録してメールを送る**」を押すと、ご本人に仮登録のご案内が届きます（7日以内に本登録。電話番号などは、ご本人が本登録で入れます）。本登録が済むと「参加中」になり、管理者全員に知らせが届きます。一覧のその行の「**詳細**」で見られ、詳細の「**編集**」で直せます。仮登録の間に直せるのは、企業名・氏名・メールアドレスの4つで、メールアドレスを変えると新しいアドレスにご案内を送り直します（前のリンクは使えなくなります）。本登録が済んだ人は、氏名・企業名・所属・役職・電話番号・郵便番号・住所を直せますが、電話番号など必須の欄は空にできません（メールアドレスは変えられません。ご自分・停止中の人のメールアドレスも変えられません）。状態が「仮登録」のまま期限（7日）が切れた人（「仮登録（期限切れ）」）には、その行の「**送り直し**」を押します。間違えて登録したときは、仮登録の行の「**取り消し**」（確認が出ます）で行を消せます。本登録が済んだ人には「取り消し」は出ません。
管理者を止めるときは、一覧のその人の行（または詳細の右上）の「**停止**」（止めているときは「**再開**」）か「**退会**」を押し、確認で「OK」を押します。ご自分の行には出ません。停止は再開で戻せますが、退会は元に戻せません（手順は 3-4）。

SES を管理者が仮登録するときは、「SES」→「SES を仮登録」。**企業正式名称・SES の姓・名・メールアドレスの4つ**を入れて「仮登録してメールを送る」を押すと、SES に仮登録のご案内が届きます（7日以内に本登録）。SES が本登録（確認コードまで）を済ませると、会社が「参加中」になり、管理者全員に知らせが届きます。一覧と詳細で、状態（仮登録・期限切れ）の確認と「送り直し」「仮登録の内容を直す」「取り消し」ができます。公開の申し込みを承認するときは、会社の詳細の「承認する」から、同じ4つの入力画面で確かめて送ります。

担当者を管理者が登録するときは、「SES」でその SES の「詳細」を開き、「担当者」の欄の「担当者を登録」を押します（参加中の SES だけ）。**姓・名・メールアドレスの3つ**を入れて「仮登録してメールを送る」を押すと、担当者に仮登録のご案内が届き、その会社の SES にも知らせが届きます。

エンジニアを管理者が登録するときは、上のメニューの「SES」でその SES の「詳細」を開き、「エンジニア」の欄の「エンジニアを登録」を押します（管理者のメニューの「エンジニア」の一覧からは登録できません）。**姓・名・メールアドレスの3つ**を入れて「仮登録してメールを送る」を押すと、ご本人に仮登録のご案内がその場で届き、SES にも知らせが届きます（ふりがな・電話・住所・同意は、ご本人が本登録で入れます）。担当者・エンジニアの行の「送り直し」「仮登録の内容を直す」「取り消し」は、本登録が済む前の方に出ます。

SES を交代するときは、「SES」の詳細の「SES の交代」で、本登録が済んだ担当者を選んで「SES にする」を押します（担当者がいない会社は、「次の SES を仮登録する」）。SES は、交代のあとでなければ停止・退会にできません。SES に属さない「直属」のエンジニアを新しく登録する入口はありません（今いる直属の人は、エンジニアの一覧に「直属」の印で出ます）。

### 3-3. エンジニアを兼ねる（兼任）

1. 管理者が自分もエンジニアとして入るときは、「SES」でその SES の詳細を開き、「エンジニアを登録」でメールアドレスに**ご自分のメールアドレス**を入れて登録します（仮登録のご案内は出ません）。
2. 「ログアウト」して入り直し、確認コードのあと、「どの立場で入りますか」で「エンジニア」を選びます。初めてのときは、足りない項目と同意の画面が出ます。
3. SES 担当者のメールアドレスで同じ SES のエンジニアを登録しても、兼任になります。「担当者を登録」「管理者を登録」でエンジニアのメールアドレスを入れると、担当者・管理者の役割が足されます。
4. 管理者の立場で自分のエンジニアの分を進めると、記録に「［本人］」が付きます。

### 3-4. 管理者・担当者・エンジニア・SES を止める・退会にする

1. 上のメニューの「SES」から、その会社の詳細を開きます。
2. 「担当者」または「エンジニア」の表の、その人の行の「停止」（止めているときは「再開」）か「退会」を押し、確認で「OK」を押します。押すと、SES の詳細に戻ります。
   - 「SES」「エンジニア」「管理者」の一覧の各行にも同じボタンがあります。一覧から押したときは、一覧（絞り込みはそのまま）に戻ります。
   - 会社ごとの停止は、「SES」の一覧の行か詳細の右上の「停止」です。停止中は「再開」で戻せます（仮登録のご案内は送りません）。
   - 管理者は、「管理者」の一覧か詳細で止めます。ご自分は止められません。使える管理者がほかにいなくなる操作もできません。
3. 内容を見たいときは「詳細」を押します。担当者の詳細の画面でも、停止・再開・退会ができます（押すと、その画面に戻ります。エンジニア兼任の人を退会にしたときは SES の詳細に戻ります）。
   - 退会は元に戻せません（記録は残ります）。
   - 稼働中の契約があるエンジニアは、退会にできません（先に契約を終了します）。
   - 使える担当者が1人だけの会社では、その人を止めたり退会にしたりできません。

## 4. メールの処理

管理者が扱うメールは、**PARK から届く知らせ**、**元請けからの案件メール**、**PARK が送ったメールの確認**の3つです。毎日の流れは、ダッシュボードのいちばん上の「**今やること**」を上から片付けるのが基本です。メールの知らせも、そこに出ます。

### 4-1. PARK から届く知らせ

どのメールにも「▼詳しくはこちら」のリンクがあり、押すと PARK の該当の画面が開きます。

| 届くメール（件名） | すること |
|---|---|
| 確認コード 123456 | ログインの画面に6桁を入れる |
| SES から参加の申し込みがありました | 「SES」から会社を開き、「**承認する**」。企業正式名称・SES の姓名・メールを確かめて送ると、SES に仮登録のご案内が届く |
| SES から案件が登録されました | 案件を開き、金額・必須スキルなどを確かめる。必要なら「エンジニアに案内する」でグループ全体に案内する |
| エンジニアが登録されました | エンジニアの詳細を開き、内容を確かめる |
| エンジニアの推薦がありました | 案件の画面の「エンジニアに案内する」→「グループのほかの人」から、推薦された人に案内する |
| 応募がありました | 応募の画面で条件を確かめ、案件に合わせたスキルシートを元請けに出して「スキルシートを提出した」（スキルは節ごとに、チェックした項目と年数が出ます） |
| 応募の取り下げ | 応募の画面で理由を確かめる |
| SES から面談依頼の報告 | 面談の画面で、面談スクリプトの中身を確かめ、必要なら直す |
| ◯◯ さんからメッセージ | 「やり取り」で読んで返事をする（「スキルシートを見てほしい」なら、スキルシートを確かめる） |
| フォロー：困りごとがあります | 契約の画面で中身を読み、本人・SES と連絡を取る |
| 案件から新しい技術を技術マスタに追加しました | 「設定」→「技術マスタ」で分類と別名を確かめ、「確認済みにする」（言い換えなら「統合」）。「使っている人」は経歴の分も数えます。統合すると経歴の索引が付け替わります（スキルのチェックは項目の名前で持つので変わりません）。確認済みにすると経歴の索引が作り直されます |

### 4-2. 元請けから案件メールが届いたら

1. 「案件」→「**案件を登録**」。
2. 案件メールの本文を「**案件メールから取り込む**」に貼り付けて「取り込む」。
3. 抜けているところ・違うところを直して「登録する」（元請けの名前は伏せ字でかまいません）。登録すると、手元の AI が必須・尚可を読み直します（1件 1分ほど）。
   - 規則と同じ数で、人が直しておらず、案内もまだなら、AI の結果が自動で入ります。
   - そうでないときは知らせが届きます。案件の画面の「**AI の読み直し**」で、違いの表を見て「AI の結果を使う」か「今のままにする」を選びます。
   - 案内したあとは、AI の結果は自動では入りません。「設定」の「AI の仕事」で、頼んだ仕事の状態を見られます。
4. 案件の画面の「**エンジニアに案内する**」で、候補を絞る → メールを作る → 送る前に確かめる → 送る。
5. 返事は、本人がリンクを押すと自動で記録されます。メールで返信が来たら、案件の画面の「案内メール」で返事を選んで「記録」します。

### 4-3. PARK が送ったメールを確かめる

1. 上のメニューの「**メール**」を開きます。送ったメールがすべて「送信箱」に残っています。
2. 「状態」が失敗のものは、エラーの中身を見て、宛先を直すなどしてから送り直します（「中身」→ 送り直す）。
3. 「届かない」と言われたときも、ここでその人宛てのメールの状態を見ます。

### 4-4. お知らせを一斉に送る

1. 「メール」の右側の「**一斉配信**」で、宛先（参加中の SES の担当者すべて・エンジニアすべてなど）を選びます。
2. 件名と本文を書いて「配信する」（宛名は自動で入ります）。
3. 確認の窓で「OK」を押すと、すぐに送られます。送る前に、宛先と本文をよく確かめてください。
