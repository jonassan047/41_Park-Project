# 用語集（Park プロジェクト）

このプロジェクトの中だけで使う言葉。全プロジェクト共通の言葉は 00_General-Guidelines の `06_Glossaries/用語集.md`。

| 言葉 | 意味 |
|---|---|
| SH | **使わない**（2026-11-23 TEZZO）。もとは「一次受けソフトハウス」の略（2026-10-14）。SES の上位は一次受けのソフトハウスでない場合が多く、SH を登場させると矛盾するため。上位の会社は「プロバイダー」と呼ぶ。それより前のログ（議事録）は SH のまま |
| SES | プロバイダーの下にいる小さな協力会社（SES の会社）。tezzo が所属していた SES は Mrsy（オーナー：阿部さん）。2026-10-14 に BP（ビジネスパートナー）から呼び名を変えた（tezzo）。それより前のログ（議事録）は BP のまま |
| EG | SES の下にいるエンジニア。tezzo も EG として働いてきた |
| 企業 | PARK の画面・文書で会社を指す言葉。「会社」とは言わず「企業」に統一し、「会社情報」は「企業情報」（2026-11-28 TEZZO）。業態・サービスとしての「SES」の呼び方はそのまま。社名（株式会社など）・自社・他社は対象外 |
| 担当者 | SES 企業の人で、PARK で担当者としてログインする人の総称。PARK窓口担当者と一般担当者（2026-11-26 から。それより前は「SES 以外の社員」の意味で使っていた） |
| PARK窓口担当者 | 企業に1人。PARK とのやり取りの窓口になる担当者（2026-11-28 TEZZO が SES代表担当者から改名）。企業を代表する人（企業代表者）とは別 |
| SES代表担当者 | **使わない**（2026-11-28 から PARK窓口担当者）。2026-11-26〜11-27 に使った。それより前は人を指して「SES」と呼んでいた |
| 一般担当者 | PARK窓口担当者以外の担当者（2026-11-26 TEZZO）。企業情報は見るだけ |
| 企業代表者 | 企業を代表する人（社長など）。企業情報の必須項目で、「窓口に同じ」（PARK窓口担当者と同じ人。表示は窓口の今の氏名）か「記入」（氏名を入れる）を選ぶ。PARK のアカウントではない。見えるのはその企業の人と管理者だけ（2026-11-28 TEZZO） |
| 代表者 | 単独では使わない（2026-11-01 TEZZO）。SES は1社に1人で、PARK に最初につながった人が名乗る。代表社員である必要はない。今の画面・マニュアルの「代表者」は、この SES（2026-11-26 から SES代表担当者）を指す（画面・マニュアルの文言は 2026-11-01 に SES へ直した） |
| 仮登録 | 上位が下位の企業名・姓・名・メールを入れ、仮登録メールを送ること。状況の表示は「仮登録中」（K15・K17。2026-11-28） |
| 参加状況 | 企業の状況（2026-11-28 TEZZO の「状態の意味が不明」を受けて整理）。申込済み・仮登録中・参加中・停止中・退会済み。画面では欄外に説明を出す |
| 登録状況 | 人のアカウント（管理者・担当者・エンジニア）の状況。仮登録中・参加中・停止中・退会済み（2026-11-28） |
| 稼働状況 | エンジニアの仕事の状況。待機中・提案中・稼働中・休止中（2026-11-28）。登録状況とは別 |
| 本登録 | 下位本人がリンクから必須項目・パスワード・同意を入れ、確認コードを通すこと。状態ではなく日時で記録し、済むと参加中になる（K11・K17・K27） |
| プレーヤー | PARK を使う立場。**管理者・PARK窓口担当者・一般担当者・EG の4つ**。担当者を抜かして3つと書かない（2026-10-31 TEZZO。呼び方は 2026-11-28 から） |
| プロバイダー | SES に案件を出してくる上位の会社（案件の必須項目。2026-11-15）。一次受けとは限らず、単に「上位」という意味（2026-11-23 TEZZO。SH の代わり）。PARK を使うプレーヤーではない |
| 受注 SES | プロバイダーから最初に案件を受け取り、その案件を PARK に登録して EG に案内する SES（DB の `source_ses_id`）。プロバイダーとは別。2026-11-23 に「提案元 SES」から呼び名を変えた（TEZZO。「みなもと」にしたが意図と違うとして、同日に「受注 SES」へ。DB の項目名・コードは変えていない）。その前は「持ち込み元」「持ち込んだ SES」（プロバイダーと紛らわしいので 2026-11-16 に改めた）。それより前のログ（議事録・History）は「提案元」のまま |
| GP | 複数の SES をグループ化したもの。EG は GP 全体で共有する |
| 商流 | 案件が、大手企業から EG まで流れる会社の連なり。多重下請け構造 |
| Park | このプロジェクトの仮の名前。EG が気楽に参加できる、というイメージ。略語ではなく、変えてよい |
| 初期費用 | 成約時に1回受け取る報酬（案件の金額の7%の案） |
| 月額費用 | 契約が続く間、毎月受け取る報酬（案件の金額の3%の案） |
