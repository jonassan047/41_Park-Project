# 用語集（Park プロジェクト）

このプロジェクトの中だけで使う言葉。全プロジェクト共通の言葉は 00_General-Guidelines の `06_Glossaries/用語集.md`。

| 言葉 | 意味 |
|---|---|
| SH | 一次受けソフトハウス（元請け）。大手企業から案件を受ける。旧表記の SF は SH に直した（2026-10-14） |
| SES | SH の下にいる小さな協力会社（SES の会社）。tezzo が所属していた SES は Mrsy（オーナー：阿部さん）。2026-10-14 に BP（ビジネスパートナー）から呼び名を変えた（tezzo）。それより前のログ（議事録）は BP のまま |
| EG | SES の下にいるエンジニア。tezzo も EG として働いてきた |
| 担当者 | SES 以外の社員（WIZ の web(Chr)。2026-10-28 TEZZO）。プレーヤーの1つで、SESとは分けて数える（2026-10-31 TEZZO）。今のアプリでは SES と担当者を分けていない |
| 代表者 | 使わない（2026-11-01 TEZZO）。SES は1社に1人で、PARK に最初につながった人が名乗る。代表社員である必要はない。今の画面・マニュアルの「代表者」は、この SES を指す（画面・マニュアルの文言は 2026-11-01 に SES へ直した） |
| 仮登録 | 上位が下位の企業名・姓・名・メールを入れ、仮登録メールを送った状態（K15・K17） |
| 本登録 | 下位本人がリンクから必須項目・パスワード・同意を入れ、確認コードを通すこと。状態ではなく日時で記録し、済むと参加中になる（K11・K17・K27） |
| プレーヤー | PARK を使う立場。**管理者・SES・担当者・EG の4つ**。「管理者・SES・EG」の3つと書かない（2026-10-31 TEZZO） |
| GP | 複数の SES をグループ化したもの。EG は GP 全体で共有する |
| 商流 | 案件が、大手企業から EG まで流れる会社の連なり。多重下請け構造 |
| Park | このプロジェクトの仮の名前。EG が気楽に参加できる、というイメージ。略語ではなく、変えてよい |
| 初期費用 | 成約時に1回受け取る報酬（案件の金額の7%の案） |
| 月額費用 | 契約が続く間、毎月受け取る報酬（案件の金額の3%の案） |
