# 2026-10-29 通しテストの手順（40_動作確認）

版：1（2026-10-29）

JOE から回された件（2026-10-29 ビジョンでの TEZZO さんの指示）。Leo が PARK アプリのコード（park のルート・画面・`resources/manuals`）で確かめて書いた。

## ねらい

PARK を、まず友人程度の小さなサークルで使い始める前に、**SES の立場で小さな成功を1つつかむ**ための、まっすぐなテスト。

上位（元請け）から来た案件メールを → SES が PARK に取り込み → エンジニアに案内し → エンジニアが「応募したい」と返し → SES が書類（Excel）を落として上位にエントリーした（「書類を返した（応募した）」）、まで。

公開版（https://www.jona.jp/park/）で、TEZZO さんが WIZ の web タブを使い、全部の立場を1人で演じる。

## 準備

### 使うタブ

| タブ | 立場 | アカウント |
|---|---|---|
| web(管理) | 管理者 | 今の TEZZO さんの管理者（そのまま） |
| web(SES) | SES の担当者 | テスト用に作る（手順 2〜6） |
| web(Eg) | エンジニア | テスト用に作る（手順 7〜11） |

- web(Chr) は今回使わない（2人目の担当者を試すときに使う）。
- タブごとに Cookie が分かれているので、3つを別の人のままログインしておける。

### メールアドレス（Gmail の「+」の別名）

Gmail は `xxxx+ses@gmail.com` のように「+」の後ろに好きな文字を足しても、いつもの受信箱に届く（`xxxx` は TEZZO さんの Gmail の @ の前）。PARK では別の人として扱われる。

| 立場 | アドレス |
|---|---|
| SES の担当者 | `xxxx+ses@gmail.com` |
| エンジニア | `xxxx+eg1@gmail.com`（2人目を試すなら `+eg2`） |

- **管理者のアドレスと同じにしない**。同じにすると「兼任」になり、ログインのたびに「どの立場で入りますか」が出て、今回のテストとは別の動きになる。
- 届くメールはどれも同じ受信箱に入る。宛先（To）の `+ses`・`+eg1` で見分ける。

### 招待メールのリンクの開き方

招待のリンクは Gmail から開くので、WIZ の web タブではなく、ふだんのブラウザで開くことになる。ふだんのブラウザが管理者でログインしたままだと混ざるので、**シークレットウィンドウ**（Chrome なら Ctrl+Shift+N）にリンクを貼って開く。パスワードの設定と最初の確認コードまで済ませたら、WIZ の web タブで入り直す（2回目からは、一度通った人には確認コードを聞かない）。

## 手順

### A. 管理者で SES を登録する（web(管理)）

**1** ログインを確かめる
- web(管理) を開く。ログインが切れていたら、右上の「ログイン」から入る。
- 確かめること：画面の上の青い帯に「管理者としてログインしています」。0 に戻したあとなので、ダッシュボードのいちばん上に「PARK をはじめましょう」が出ている。

**2** SES を登録する
- 上のメニューの「SES」→「SES を登録」。
- 会社名：`テストSES（通しテスト）`、担当者名（姓）：`テスト`、（名）：`担当`、メールアドレス：`xxxx+ses@gmail.com`。ほかは空でよい。
- 「登録して招待メールを送る」を押す。
- 確かめること：SES の一覧に「参加中」で出る。ダッシュボードの「招待の状況」に担当者が「招待中」で出る。

### B. SES の担当者の初回ログイン（シークレットウィンドウ → web(SES)）

**3** 招待のリンクを開く
- Gmail で、宛先が `+ses` の「ご招待：パスワードを設定してください」を開き、リンクをシークレットウィンドウで開く。
- 「パスワードの設定」で、パスワード（8文字以上）を2回入れ、守秘義務への同意にチェックを入れて「設定して始める」。
- 確かめること：「確認コード」の画面に移る。

**4** 確認コードを入れる
- Gmail に届いた「確認コード 123456」（宛先 `+ses`）の6桁を入れて「ログイン」。10分で切れる。
- 確かめること：「あなたの情報」の画面が出る。

**5** あなたの情報を登録する
- 氏名（姓・名）を入れる。SES名には `テストSES（通しテスト）` が入っているので、そのままでよい。「登録する」。
- 確かめること：ダッシュボードが開き、帯に「SES（テストSES（通しテスト））のご担当者としてログインしています」。
- ここでシークレットウィンドウは閉じてよい。

**6** web(SES) で入り直す
- WIZ の web(SES) を開き、右上の「ログイン」→ `xxxx+ses@gmail.com` とパスワードで「ログイン」（確認コードを聞かれたら、届いた6桁を入れる）。
- 確かめること：手順 5 と同じ帯が出る。web(管理) に戻っても管理者のまま（タブで人が混ざらない）。

### C. SES でエンジニアを登録する（web(SES)）

**7** エンジニアを登録する
- 上のメニューの「エンジニア」→「エンジニアを登録」。
- 氏名（姓）：`テスト`、（名）：`太郎`、ふりがな：`てすと`・`たろう`、メールアドレス：`xxxx+eg1@gmail.com`、IT の経験年数：`5`、希望単価：`62`、下限の単価：`55`、稼働できる日：`2026-12-01`、希望の働き方：「どちらでも」。
- 「登録して招待メールを送る」を押す。
- 確かめること：エンジニアの一覧に出る。ダッシュボードの「ご本人の確認がまだのエンジニア」に出る。

### D. エンジニアの初回ログインとスキル登録（シークレットウィンドウ → web(Eg)）

**8** 招待のリンクを開く
- Gmail で、宛先が `+eg1` の「ご招待：パスワードを設定してください」のリンクを、シークレットウィンドウで開く。
- パスワードを2回入れ、「個人情報の取り扱い」の「上の取り扱いに同意します」にチェックを入れて「設定して始める」。

**9** 確認コードを入れる
- 宛先 `+eg1` の「確認コード」の6桁を入れて「ログイン」。

**10** あなたの情報を登録する
- 氏名（姓・名）を入れて「登録する」。
- 確かめること：ホームが開き、帯に「エンジニアとしてログインしています」。「今やること」に「登録の内容」が出ている。シークレットウィンドウは閉じてよい。

**11** web(Eg) で入り直す
- WIZ の web(Eg) で「ログイン」→ `xxxx+eg1@gmail.com` とパスワード。
- 確かめること：手順 10 と同じ帯。web(SES) は SES のまま。

**12** スキルを登録する
- 上のメニューの「プロフィール」→「スキルを編集」。「行を足す」で次の5つを入れ、「保存する」。

| スキル | 年数 |
|---|---|
| Java | 5 |
| Spring Boot | 3 |
| PostgreSQL | 3 |
| Git | 5 |
| Linux | 3 |

- レベルは好きなものでよい。
- 確かめること：プロフィールにスキルが5つ出る。

**13** 経験の案件を1件足す（書類が空にならないように）
- プロフィールの「案件を追加」。案件名（必須。例：`物流会社向け 在庫管理システムの改修`）・役割（`SE`）・開始（年月）・使った技術（`Spring Boot`）・言語（`Java`）・DB（`PostgreSQL`）・作業内容を入れて保存する。架空の内容でよい。
- 確かめること：「経験票に追加しました。」と出て、プロフィールに案件が1件出る。

**14** 「確認しました」を押す
- ホームの「登録の内容の確認」→「内容を確認しました（責任を持って登録します）」→ 確認の窓で「OK」。
- 確かめること：ホームの「登録の内容の確認」と「今やること」の項目が消える。web(SES) のダッシュボードの「ご本人の確認がまだのエンジニア」からも消える。
- 注意：このあと SES（または管理者）がエンジニアの内容を書き換えると、確認がやり直しになり、応募できなくなる（手順 24 で止まる）。書き換えたら、もう一度ここを押す。

### E. SES で案件メールを取り込む（web(SES)）

**15** 案件メールを貼って取り込む
- 上のメニューの「案件」→「案件を登録」。
- 下の「案件メールの見本」の囲みの中を全部コピーし、「案件メールから取り込む」に貼り付けて「取り込む」。

**16** 中身を確かめて登録する
- 確かめること（自動で入っていればよい）：

| 項目 | 入っていればよい値 |
|---|---|
| 案件名 | 物流会社向け 在庫管理システムの機能追加（Java／Spring Boot） |
| 金額（万円／月） | 65 |
| 必須スキル | Java、Spring Boot、PostgreSQL |
| 尚可スキル | AWS、Docker（ほかに本文から見つけた技術が足されることがある） |
| 経験年数（以上） | 3 |
| 働き方 | 一部リモート |
| 場所 | 東京都江東区（最寄り：架空駅）… |
| 開始 | 2026-12-01 |
| 面談回数・募集人数 | 1・1 |

- 元請け（伏せ字でよい）に `SH-テスト` を入れる。違うところがあれば直す。
- 「登録する」を押す。
- 確かめること：案件の画面が開く。web(管理) のベルに「SES から案件が登録されました」が出る（メールも管理者のアドレスに届く）。

### F. エンジニアに案内する（web(SES)）

**17** 送る相手を絞る
- 案件の画面の「案内メール」の右上（または右側）の「エンジニアに案内する」。
- 「1. 送る相手を絞る」に テスト 太郎 が点数付きで出ている。チェックが入っていることを確かめる。

**18** メールを作る
- 「2. メールを作る」：送り方は「すべて同じ内容で送る」、件名・本文はそのまま。「送る前に確かめる」。

**19** 送る
- 確かめること：一人分の本文に、宛名（テスト 太郎）・単価（65万円）・必須スキルが入っている。「提案」に大きな問題（点数が低い、など）が出ていない。
- 「送る」を押す。
- 確かめること：「1名に案内メールを送りました」と出て、案件の画面の「案内メール」の表に テスト 太郎 の行（返事：返事なし）ができる。

### G. エンジニアが「応募したい」を押す（Gmail → ふだんのブラウザ）

**20** 案内メールを開く
- Gmail で、宛先 `+eg1` の「【案件のご案内】物流会社向け 在庫管理システムの機能追加…」を開く。
- 確かめること：本文に案件の中身があり、最後に「応募したい／質問がある／見送る」のリンクがある。

**21** 返事をする
- 「応募したい」のリンクを押す（ログインは要らない。ふだんのブラウザで開いてよい）。
- 「ご返事」が「応募したい」になっていることを確かめ、ひとこと（例：`ぜひお願いします`）を書いて「この内容で返事をする」。
- 確かめること：「ご返事を受け付けました」の画面。

**22** SES 側に届いたか確かめる
- 確かめること：Gmail（宛先 `+ses`）に「テスト 太郎 さん 応募したい：…」のメールが届く。web(SES) で案件の画面を開き直すと、「案内メール」の テスト 太郎 の返事が「応募したい」になり、「書類を返した（応募した）」のボタンが出ている。

### H. SES が書類を落として「書類を返した（応募した）」を押す（web(SES)）

**23** 書類（Excel）をダウンロードする
- 案件の画面の「案内メール」の表の右の列「案件をくれた先へ返す書類」で、「履歴書」「業務経歴書」「業務経歴書（名前を伏せる）」を押す。
- 確かめること：Excel が落ちてきて開ける。名前・スキル（手順 12）・経験の案件（手順 13）が入っている。名前を伏せた版にはイニシャル（T.T）が出て、住所・電話は出ない。
- WIZ のタブで押しても何も起きないときは、シークレットウィンドウで SES のアドレスでログインし直して、そこから落とす（WIZ の中のダウンロードの動きは未確認）。
- 本物の上位にはメールを送らない。テストなので、送ったことにして次へ進む。

**24** 「書類を返した（応募した）」を押す
- 案件の画面の テスト 太郎 の行の「書類を返した（応募した）」を押す。
- 確かめること：
  - 応募の画面が開き、「応募したことを記録しました。面談依頼が来たら、この画面の「面談依頼が来た」に入れてください。」と出る。状態は「書類提出」。
  - web(SES) の「応募・選考」に、この応募が出る。
  - web(Eg) の「応募・面談」に、この応募が出る（ベルにも知らせ）。
  - web(管理) の「応募・選考」（管理者のメニュー）にも出る。

ここまで通れば、通しテストは成功。

（続けたいとき：面談依頼 → 面談の結果 → 成約、は SES の操作手順書の「4-5」。今回の範囲の外。）

## 案件メールの見本

上位（元請け）から届いた形の、架空の案件メール。会社名・駅名・案件はすべて架空。下の囲みの中を全部コピーして、手順 15 で貼る。

```
お世話になっております。
株式会社カクウソフト（架空）営業部です。

下記につきまして、ご提案いただける方がいらっしゃいましたら
スキルシートを添えてご返信ください。

■案件名：物流会社向け 在庫管理システムの機能追加（Java／Spring Boot）
■作業内容：
既存の在庫管理システム（Web）への機能追加と改修。
詳細設計から製造、単体テスト、結合テストまで。
■必須スキル：Java、Spring Boot、PostgreSQL
■尚可スキル：AWS、Docker
■単価：60～65万円／月（スキル見合い）
■精算：140～180h
■場所：東京都江東区（最寄り：架空駅）リモート併用（週2日出社）
■開始時期：2026年12月
■期間：3か月ごとの更新（長期予定）
■面談：1回（オンライン）
■募集人数：1名
■備考：Java の実務経験3年以上の方

以上、よろしくお願いいたします。
株式会社カクウソフト（架空）営業部
```

- 取り込みの解析は、「■案件名：」「■単価：」のように、行の頭の見出し（案件名・単価・必須・場所・開始など）で項目を見分ける。単価は「万」の前のいちばん大きい数（65）、開始は「2026年12月」から 2026-12-01、働き方は「リモート」と「出社」の両方があるので「一部リモート」、経験年数は「3年以上」から 3 になる（park の `app/Services/CaseParser.php`）。
- エンジニアのスキル（手順 12）は、必須の3つ（Java・Spring Boot・PostgreSQL）を全部持ち、単価（下限 55・希望 62）も開始（2026-12-01 から稼働できる）も合うようにしてある。

## 片付け（必要なら）

テストのデータは、残しておいても困らない（まわりに見えるのは、ログインした管理者・その SES・そのエンジニアだけ）。どれにするかは TEZZO さんが決める。

- a. **残す**（おすすめ）：もう一度通しテストをするときや、面談・成約の流れを試すときにそのまま使える。案件だけ閉じるなら、案件の画面の「編集」で状態を「終了」にして「保存する」。
- b. **退会にする**：web(管理) の「SES」の一覧で `テストSES（通しテスト）` の行の「退会」→「OK」。所属のエンジニアも一緒に退会済になり、ログインできなくなる（記録は残る。元に戻せない）。同じアドレスでもう一度試すときは、`+ses2`・`+eg2` など別の別名を使う。
- c. **0 に戻す**：2026-10-28 と同じく、管理者だけを残して全部消す。phpMyAdmin で SQL を流す作業で、データの削除にあたるので、TEZZO さんの了承をもらってから Leo が SQL を用意する。
